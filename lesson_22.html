Module 8 • Lesson 2🎨 Studio Session — Build It

🧠 Mental Model: Work in Passes

Amateurs try to finish one corner perfectly, then the next. Professionals work the whole image in passes, each raising the finish level everywhere before going deeper. A block-in pass gets every element placed roughly right. A refine pass fixes selections, light, and color across the frame. A polish pass adds the small, high-value details last.

Passes protect you from two traps: sinking hours into a corner you later cut, and losing the whole-image balance while zoomed to 300%. Zoom out between passes and judge the frame, not the pixel. The image is done when a pass changes almost nothing — not when you run out of things you could do.

🗂️ Layer Hygiene

A big composite is only as editable as its layer stack is organized. Group by role, name everything, and color-label groups so the panel reads at a glance. Keep every adjustment as a live layer, every scaled element a Smart Object, every filter a Smart Filter — so any decision stays reversible to the end.

⚠️ Save versions, and save often

Save incrementally — capstone_v01, v02 — at each pass, so a bold experiment is never a one-way door. Keep a flattened "reference" JPG of milestones too, so you can compare where you were with where you are. Crashes and regrets both get much cheaper.

👀 Judging Your Own Work

The hardest part of finishing is seeing your work as a stranger would. You go blind to your own image after an hour. A few reliable tricks force fresh eyes:

  • Flip horizontal (View ▸ Flip Horizontal, which flips only the view; older versions use Image ▸ Image Rotation ▸ Flip Canvas Horizontal, so flip back after) — composition and balance errors leap out in the mirror.
  • Zoom to fit and squint — if the focal point and read survive at thumbnail size and blurred, the structure is sound.
  • Desaturate to check — a temporary Black & White adjustment layer at the very top of the stack (toggle it off when done) exposes tonal problems that color hides.
  • Walk away — even ten minutes resets your eye; a night is better. Compare against the brief and moodboard, not your last zoom.

✅ Grade against the brief, not your mood

When you think you are done, open the brief's success criteria and check each one. "Done" is meeting the brief at a high polish — not exhaustion, and not endless fiddling past the point of improvement.

🛠️ Guided Build: The Studio Session

Open a new document at your brief's largest size. Bring in your plan and moodboard. Work the passes — this is your session, take the time it needs.

Pass 1: Block-in · structure

  1. Source and roughly place every element. Cut out subjects (Module 1). Get scale and position right against the horizon (Module 4.1).
  2. Set up your groups and name them now, while the file is small.

Pass 2: Refine · light, color, edges

  1. Correct color and set the working space (Module 2). Retouch subjects (Module 3). Match light and build shadows (Module 4.2). Tighten every mask.
  2. Lay in the type system (Module 5.1) and any templated elements (5.2).

Pass 3: Polish · atmosphere, grade, details

  1. Add depth and atmosphere, then the single unifying grade on top (Module 4.3). Bring in multi-shot elements if your brief uses them (Module 7).
  2. Final details: rim light, grain, vignette. Run the fresh-eyes checks. Automate any repetitive export (Module 6).

Finish: check against the brief · the gate

  1. Open your 8.1 success criteria and tick each one on the artwork.
  2. Save the layered master and export the deliverables at spec. The capstone artwork is done. 🏆

✅ Project Completion Checklist

  • ☐ Built in passes, whole-image at each level
  • ☐ Grouped, named, color-labeled, non-destructive layer stack
  • ☐ Incremental versions saved along the way
  • ☐ Fresh-eyes checks (flip, squint, desaturate, walk away) done
  • ☐ Every brief success criterion met and ticked
  • ☐ Layered master saved; deliverables exported at spec

🧗 Now You: Push It Further

🌟 Stretch your capstone

  1. Produce an alternate grade or a day/night variant from the same master to show range (Modules 4.3, 5.2).
  2. Spin the hero into a sized campaign set (Module 5.3) or a short animated version (Module 7.2).
  3. Record the repetitive export as an Action or data set (Module 6) so the whole deliverable set ships in one pass.

Going further: keep a running screenshot at the end of each pass. You'll need those progress shots for the case study in the next lesson — capture them while you build, not after.

🍳 Recipe Card: Studio Session

Build clean, in passes

  1. Pass 1 block-in (place, scale, group + name early)
  2. Pass 2 refine (color, retouch, light/shadow, masks, type)
  3. Pass 3 polish (atmosphere, unifying grade, details)
  4. Stay non-destructive; save versions each pass
  5. Fresh-eyes check, then grade against the brief

Mantra: raise the whole image a level at a time, and keep every decision reversible.

📝 Lesson Summary

🎓 Key Takeaways

  • Work in passes (block-in, refine, polish), raising the whole image a level at a time.
  • Layer hygiene: group by role, name everything, color-label groups, and keep adjustments, Smart Objects, and Smart Filters live.
  • Save versions at each pass so bold experiments are never one-way doors.
  • Judge with fresh eyes (flip, squint, desaturate, walk away), then grade against the brief.

🎉 What You've Accomplished

You built your capstone artwork through the full pipeline in a clean, editable file, checked it against every success criterion in your brief, and exported the deliverables at spec. That is a finished professional project, not an exercise.

❓ Common Questions at This Stage

My file is getting slow and huge. What do I do?

Convert heavy element groups to Smart Objects (or linked ones), rasterize truly final elements you're sure of, purge history (Edit ▸ Purge ▸ Histories), and keep working resolution sensible. Good hygiene from Pass 1 is the real fix; these are the mid-project rescues.

How do I know when it's actually finished?

When a fresh-eyes pass changes almost nothing and every brief success criterion is met. If you're only moving things a pixel back and forth, you're past done: save it and present it.
