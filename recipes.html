🎭 Advanced Selection & Masking

Build a luminosity mask

When you want to grade only the brightest (or darkest) tones.

  1. Ctrl/⌘-click the RGB channel thumbnail to load the highlights (Lights) as a selection.
  2. To tighten the Lights, Ctrl/⌘+Shift+Alt/⌥-click the RGB thumbnail again (intersect). For darks, Select ▸ Inverse (Ctrl/⌘+Shift+I); to tighten darks, save that selection as a channel (Select ▸ Save Selection) and intersect with that channel, not RGB.
  3. Add an adjustment layer (Curves is the classic choice); the luminosity selection becomes its mask.

🔗 Deep dive: Lesson 1.1: Luminosity Masks: Select by Tone

Mask from the best channel

When a subject separates strongly in one color channel.

  1. In Channels, click Red, Green, and Blue in turn and pick the one with the most subject/background contrast.
  2. Duplicate it, then push contrast hard with Image ▸ Adjustments ▸ Levels (or Curves) to near black and white; clean gaps with a hard brush on the channel.
  3. Ctrl/⌘-click the copy to load it, invert if the background loaded (white loads first), click RGB to return to the composite, then add a layer mask.

🔗 Deep dive: Lesson 1.2: Channel Masking & Blend-If

Drop a tone with Blend-If

When you want to hide a bright sky or dark backdrop instantly.

  1. Double-click the layer (on the thumbnail or empty area, not the name) to open Blending Options.
  2. Under Blend If, drag the This Layer white (or black) slider inward.
  3. Alt/⌥-drag to split the slider for a soft, halo-free transition.

🔗 Deep dive: Lesson 1.2: Channel Masking & Blend-If

Cut out fine hair cleanly

When Select Subject leaves a chopped or haloed hairline.

  1. Select ▸ Subject, then Select ▸ Select and Mask (Ctrl+Alt+R / ⌘+⌥+R).
  2. Turn on Smart Radius, run the Refine Edge Brush along the wispy edge only, keep Smooth/Feather low, and nudge Shift Edge slightly negative. Output to New Layer with Layer Mask.
  3. Rescue missed strands by loading a channel mask and painting white into the layer mask.
  4. Final pass: reopen Select and Mask on the rescued mask, tick Decontaminate Colors, and output to New Layer with Layer Mask.

🎨 Color, Tone & Grade

Set up a safe color pipeline

When colors shift between apps, screens, or on export.

  1. Edit ▸ Color Settings: pick a working space (sRGB for web, Adobe RGB / ProPhoto for wide work) and set the policies to Preserve Embedded Profiles.
  2. Work in 16-bit for grading headroom (Image ▸ Mode ▸ 16 Bits/Channel).
  3. Deliver at the very end, on a duplicate, with Edit ▸ Convert to Profile, not Assign. Convert keeps the appearance.

🔗 Deep dive: Lesson 2.1: Color Management & Working Spaces

Grade with a Gradient Map

When you want a cohesive, tone-mapped color look fast.

  1. Add a Gradient Map adjustment layer.
  2. Build a dark-to-light gradient: cool shadow color → warm highlight color (e.g. teal → gold).
  3. Set the layer to Color or Soft Light and drop its opacity to about 20–30% so it tints rather than flattens.

🔗 Deep dive: Lesson 2.2: Grading with Curves, Gradient Maps & LUTs

Save & reuse a grade as a LUT

When you want one grade to travel across images (or into video).

  1. Build your grade with adjustment layers above a Background layer.
  2. The export bakes every visible adjustment layer and a LUT can't store a mask, so hide anything that isn't part of the grade and disable masks (Shift-click each mask thumbnail).
  3. File ▸ Export ▸ Color Lookup Tables to write a .cube, then re-enable the masks.
  4. Apply anywhere with a Color Lookup adjustment layer.

🔗 Deep dive: Lesson 2.2: Grading with Curves, Gradient Maps & LUTs

Match two images' color

When a set must read as one shoot.

  1. Match tones first (brightness/contrast), then color.
  2. Drop a Color Sampler on a comparable point in each image and read them in the Info panel.
  3. Add Curves to one and move each channel until its sampled values meet the reference: black point, then white point, then mid color.

🔗 Deep dive: Lesson 2.3: Match, Split-Tone & Soft-Proof

Split-tone a photo

When you want cinematic cool shadows and warm highlights.

  1. Add a Color Balance layer with Preserve Luminosity ticked.
  2. On Shadows push toward cyan/blue; on Highlights toward red/yellow.
  3. Keep Midtones near neutral so skin stays believable.

🔗 Deep dive: Lesson 2.3: Match, Split-Tone & Soft-Proof

Soft-proof for print

When a grade must survive on paper, not just screen.

  1. View ▸ Proof Setup ▸ Custom: choose the printer profile, a Rendering Intent with Black Point Compensation, and tick Simulate Paper Color.
  2. Toggle proof with Ctrl/⌘ + Y; the image dulls, and that's the paper.
  3. Turn on Gamut Warning (Shift+Ctrl/⌘+Y) and desaturate flagged areas.

🔗 Deep dive: Lesson 2.3: Match, Split-Tone & Soft-Proof

🧑‍🎨 High-End Retouching

Set up frequency separation

When you must even skin tone without erasing pores.

  1. Duplicate twice → Low (bottom) and High (top). Hide High, then Gaussian Blur Low until pores vanish; note the radius.
  2. On High: Apply Image with source Low. In 8-bit: Subtract, Scale 2, Offset 128. In 16-bit: Add, tick Invert, Scale 2, Offset 0. Then set the blend mode to Linear Light.
  3. Even tone on Low; heal blemishes on High (Healing Brush, Sample: Current Layer). Never work on both at once.

🔗 Deep dive: Lesson 3.1: Skin & Frequency Separation

Dodge & burn on a gray layer

When a portrait is clean but flat and needs form.

  1. New layer, mode Soft Light, tick Fill with Soft-Light-neutral color (50% gray).
  2. Soft brush, Flow 5–10%: white to dodge highlights, black to burn recesses.
  3. Check in a temporary Black & White view; lower opacity to taste.

🔗 Deep dive: Lesson 3.2: Dodge & Burn Sculpting

Whiten teeth naturally

When teeth read yellow or dull.

  1. Add a Hue/Saturation layer; on Yellows, drop saturation first.
  2. On Master, raise Lightness slightly. (Yellow out, then brighten.)
  3. Invert the mask to black (Ctrl/⌘+I) and paint the effect onto the teeth only.

🔗 Deep dive: Lesson 3.3: Eyes, Teeth & Hair — Natural Finish

Make eyes pop (subtly)

When eyes need life without looking fake.

  1. Add a Curves layer, lift midtones; invert the mask and paint the iris and whites.
  2. Optionally add a High-Pass-sharpened layer masked to the iris.
  3. Never paint out the catchlight, and keep whites off-white.

🔗 Deep dive: Lesson 3.3: Eyes, Teeth & Hair — Natural Finish

🖼️ Compositing

Scale an element correctly

When a pasted person or object looks the wrong size.

  1. Find the scene's horizon by extending its receding edges to a vanishing point.
  2. Set the element's ground-contact point first.
  3. Scale so the horizon crosses it at the same body height as the scene's people.

🔗 Deep dive: Lesson 4.1: Match Perspective, Scale & Lens

Build a believable cast shadow

When a composited element casts none and looks pasted.

  1. Ctrl/⌘-click the element's layer mask thumbnail (or layer thumbnail) to load its silhouette. On a new layer below it, Edit ▸ Fill with a very dark color, deselect, and set Multiply.
  2. Free Transform ▸ Distort/Skew onto the ground, running away from the light.
  3. For blur that grows with distance, use Filter ▸ Blur Gallery ▸ Tilt-Shift or Field Blur (sharp near the object, soft at the far end); fade it with a gradient mask and tint it to the scene's shadows (cool outdoors).

🔗 Deep dive: Lesson 4.2: Light, Shadows & Reflections

Anchor with a contact shadow

When an element still floats even with a cast shadow.

  1. New layer under the element, mode Multiply.
  2. Small soft black brush at low flow: darken exactly where the base meets the ground.
  3. Keep it tight and barely blurred; this is what reads as "touching."

🔗 Deep dive: Lesson 4.2: Light, Shadows & Reflections

Add depth with atmosphere

When background elements feel pasted forward.

  1. On far elements, lower contrast and lift the blacks slightly.
  2. Glaze a low-opacity haze in the sky/scene color over them.
  3. Keep the nearest element crispest and most saturated.

🔗 Deep dive: Lesson 4.3: Atmosphere & the Unifying Grade

Unify a composite with one grade

When pieces look like separate photos side by side.

  1. Correct every element to neutral first.
  2. Put a single grade (Color Lookup, or Curves + Color Balance) at the top of the stack.
  3. It affects every layer below, giving them one shared color.

🔗 Deep dive: Lesson 4.3: Atmosphere & the Unifying Grade

🔠 Design Systems & Type

Build a type scale & styles

When a layout's type sizes feel arbitrary.

  1. Pick a base size and a ratio (e.g. 16 × 1.25) → a modular scale; assign roles.
  2. Style one sample line per role, then create a named Paragraph Style (and Character Styles where needed) from it. Use real OpenType weights, never faux bold/italic.
  3. Edit a style once and every instance updates.

🔗 Deep dive: Lesson 5.1: Type Systems, Styles & Grids

Set columns & a baseline guide

When elements don't line up across a layout.

  1. View ▸ Guides ▸ New Guide Layout (older versions: View ▸ New Guide Layout): set columns, gutters, and margins.
  2. Photoshop has no true baseline grid. Approximate one in Preferences ▸ Guides, Grid & Slices: set Gridline Every to your body leading with Subdivisions 1, give your text that leading (or a multiple), and show it with View ▸ Show ▸ Grid (Ctrl/⌘+').
  3. Text won't snap to it, so align each text block's first baseline to a gridline by eye.

🔗 Deep dive: Lesson 5.1: Type Systems, Styles & Grids

Make a reusable mockup

When you drop different art onto the same surface repeatedly.

  1. Put a rectangle where the art goes, Convert to Smart Object, and Edit ▸ Transform ▸ Warp (or Perspective Warp) it to the surface.
  2. Add the surface's shadows (Multiply) and highlights (Screen) above it, clipped.
  3. Swap art any time with Layer ▸ Smart Objects ▸ Replace Contents; the treatment stays.

🔗 Deep dive: Lesson 5.2: Smart-Object Templates & Linked Assets

Spin one design into many sizes

When a campaign needs poster, square, story, and banner.

  1. Use Artboards (one per size); design the largest first.
  2. Place Linked the shared logo/art into each so one edit updates all; apply shared Paragraph Styles; recompose per aspect ratio and respect safe zones.
  3. File ▸ Export ▸ Export As with all artboards selected renders the whole set at once (or use File ▸ Export ▸ Artboards to Files).

🔗 Deep dive: Lesson 5.3: Campaign from One Master

⚙️ Generative, Automation & Multi-Shot

Extend, clean & harmonize with generative tools

When a composite is cramped or has a distraction.

  1. Generative Expand (Crop tool out past the canvas, empty prompt) for room; audit the new edges.
  2. Generative Fill with an empty prompt to erase a distraction.
  3. In current versions, select a pasted-in element's layer and choose Harmonize (contextual task bar or Properties panel; placement varies by release, and it uses generative credits) to match its light and color to the scene. Mask back anything it shouldn't change.
  4. Grain/sharpen-match generated areas and hand-blend; keep each result on its own generative layer.

🔗 Deep dive: Lesson 6.1: Generative for Compositing

Batch a folder with a conditional

When mixed landscape/portrait files all need the same prep.

  1. Record an Action with relative steps (File ▸ Automate ▸ Fit Image for the long edge, rulers in Percent, sharpen, Flatten Image, save as JPG). Record separate crop actions for landscape and portrait.
  2. Select the first step, then Actions panel menu ▸ Insert Conditional: If Document Is Landscape play one crop action, else the other. It lands below the selected step, so drag it to the top so the crop runs before Fit Image.
  3. File ▸ Automate ▸ Batch over the folder: tick Override Action "Save As" Commands, Suppress File Open Options Dialogs and Suppress Color Profile Warnings, and set Errors to Log Errors to File.

🔗 Deep dive: Lesson 6.2: Advanced Actions & Conditionals

Mass-produce from a spreadsheet

When you need hundreds of graphics that differ only by data.

  1. Image ▸ Variables ▸ Define (Text / Pixel / Visibility); name each variable to match its CSV header exactly (the layer name can match too, but it's the variable name that binds).
  2. Image ▸ Variables ▸ Data Sets… ▸ Import a UTF-8 CSV with a header row; tick Use First Column For Data Set Names. Visibility values are true/false; Pixel values are full file paths, or bare file names with the images in the CSV's folder. Step through rows to proof.
  3. File ▸ Export ▸ Data Sets as Files to render every row as a PSD.

🔗 Deep dive: Lesson 6.3: Data-Driven Graphics & Scripting

Merge many frames into one

When one frame can't hold the width, range, or depth you need.

  1. Panorama: File ▸ Automate ▸ Photomerge (Auto + Blend Images Together + Content Aware Fill Transparent Areas).
  2. HDR: File ▸ Automate ▸ Merge to HDR Pro (bracket, Remove Ghosts; 16-bit to tone-map in the dialog, or 32-bit to keep the full range).
  3. Focus stack: File ▸ Scripts ▸ Load Files into Stack (tick Attempt to Automatically Align, or run Edit ▸ Auto-Align Layers) → Edit ▸ Auto-Blend Layers… (Stack Images).

🔗 Deep dive: Lesson 7.1: Panoramas, HDR & Focus Stacking

Export a looping GIF or MP4

When a design needs a few seconds of motion.

  1. Window ▸ Timeline, click Create Video Timeline; keyframe Position/Opacity/Style, or Transform on Smart Objects (stopwatch).
  2. Return every layer to its frame-0 state by the last frame for a seamless loop; fake easing with an extra keyframe near the end of each move.
  3. GIF: File ▸ Export ▸ Save for Web (Legacy) (Ctrl+Alt+Shift+S / ⌘+⌥+Shift+S), Looping Options: Forever. MP4: File ▸ Export ▸ Render Video (H.264).

🔗 Deep dive: Lesson 7.2: Timeline Animation & Export
