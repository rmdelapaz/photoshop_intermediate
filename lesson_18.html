👤 The Goal: One Template, Hundreds of Outputs

A batch of personalized cards. On the right, the manual way: duplicate the file, retype the name, swap the photo, save — per person, forever. On the left, one template plus a CSV; Photoshop renders every row automatically. Drag the handle:

🧠 Mental Model: Template + Data

A data-driven document has two halves. The template is your design with certain layers marked as variable. The data is a table where each column maps to a variable and each row is one output. Photoshop's Variables feature binds them: define which layers change and how, import the table as Data Sets, and each row becomes a finished graphic.

There are exactly three kinds of variable: Text Replacement (swap the words in a type layer), Pixel Replacement (swap the image in a layer, with fit rules), and Visibility (show or hide a layer). Almost any personalized-graphics job decomposes into those three.

🧮 Variables & Data Sets

Open Image ▸ Variables ▸ Define, pick a layer, tick the variable types it needs, and name each variable to match a CSV column. Then open Image ▸ Variables ▸ Data Sets… and click Import to load the CSV; with Preview on, the Data Set menu lets you step through rows and see each on the canvas. Finally File ▸ Export ▸ Data Sets as Files renders one PSD (or, via an Action, a JPG/PNG) per row.

⚠️ Name layers and columns to match

Each variable binds to the CSV column whose header matches its variable name, and a stray space or capital mismatch breaks the import. Variable names can't contain spaces and must start with a letter, underscore, or colon. Naming the layer the same is a helpful habit, not a requirement. Keep the CSV UTF-8 with a header row, write Visibility values as true/false, and give Pixel Replacement values as full file paths (or just file names, with the images in the same folder as the CSV). Proof a few rows on-canvas before exporting five hundred.

💻 Where Scripting Begins

Variables cover "same layout, different content." When you need real logic — loop over files, do math, rename by pattern, call an API, decide based on pixel values — you reach for scripting. Photoshop runs classic ExtendScript (.jsx) and newer UXP scripts (.psjs) via File ▸ Scripts ▸ Browse. The example below is ExtendScript, which is still the easiest to find snippets for. You do not need to be a programmer to adapt a snippet.

Here is a complete, readable example: open every JPG in a folder, resize to 2000px on the long edge, and save a web copy — the kind of loop an Action alone can't express cleanly:

// resize-folder.jsx  —  File ▸ Scripts ▸ Browse to run
var inputFolder  = Folder.selectDialog("Choose a folder of images");
if (!inputFolder) { throw new Error("No folder chosen."); }
var files = inputFolder.getFiles(/\.(jpg|jpeg|png)$/i);

for (var i = 0; i < files.length; i++) {
    var doc = app.open(files[i]);
    var longEdge = 2000;
    var scale = longEdge / Math.max(doc.width.value, doc.height.value);
    doc.resizeImage(doc.width * scale, doc.height * scale);

    var out = new File(inputFolder + "/web_" + doc.name.replace(/\.[^.]+$/, ".jpg"));
    var opt = new JPEGSaveOptions();
    opt.quality = 10;
    doc.saveAs(out, opt, true);
    doc.close(SaveOptions.DONOTSAVECHANGES);
}
alert("Done: " + files.length + " images resized.");

✅ You can read code before you can write it

Notice you can already follow this: pick a folder, loop the files, compute a scale, resize, save, close. Start by tweaking values (the 2000, the quality) in snippets like this. Reading and adapting is a real, employable skill on its own.

🛠️ Guided Build: A Data-Driven Batch

Design a simple card template with a name (type layer), a photo (image layer), and a "SALE" badge (a layer to show/hide). Prepare a small CSV with columns name, photo, sale: put the photos in the same folder as the CSV, list their file names in the photo column, and write true or false in the sale column.

Step 1: Name everything · 8 min

  1. Rename the layers exactly: name, photo, sale. You'll give the variables the same names, and the CSV headers must match the variable names.

Step 2: Define variables · 12 min

  1. Image ▸ Variables ▸ Define. On name tick Text Replacement; on photo tick Pixel Replacement (set the method: Fit, Fill, As Is, or Conform); on sale tick Visibility. Name each variable to match its CSV header.

Step 3: Import and proof · 10 min

  1. Image ▸ Variables ▸ Data Sets… ▸ Import your CSV. Tick Use First Column For Data Set Names (your first column is name). With Preview on, step through a few rows and confirm the name, photo, and badge update correctly on canvas.
  2. Fix any binding that didn't take (usually a header/variable-name mismatch, a yes/no instead of true/false, or a photo path Photoshop can't find).

Step 4: Export the batch · 8 min

  1. File ▸ Export ▸ Data Sets as Files. In File Naming, choose Data Set Name (the name column, thanks to the import option), add any fixed text you like, and export. Photoshop writes one PSD per row.
  2. Optional: run them through your Lesson 6.2 delivery Action to flatten to JPG. Module 6 deliverable: a folder of finished, personalized graphics from one template. 🏆

✅ Project Completion Checklist (Module 6 deliverable)

  • ☐ Variable names (and layers) matching the CSV headers exactly
  • ☐ Text, Pixel, and Visibility variables defined
  • ☐ CSV imported as a data set, several rows proofed on canvas
  • ☐ Data Sets exported as files with a clear naming pattern
  • ☐ (Optional) finished via a delivery Action / droplet

🍳 Recipe Card: Data-Driven

Template + data → batch

  1. Name layers to match CSV headers exactly
  2. Image ▸ Variables ▸ Define: Text / Pixel / Visibility
  3. Image ▸ Variables ▸ Data Sets… ▸ Import the CSV (first column as names; Visibility = true/false); proof rows on canvas
  4. File ▸ Export ▸ Data Sets as Files, named by Data Set Name
  5. Reach for scripting when you need loops, math, or logic

Mantra: design the difference as data, and the count stops mattering.

❓ Common Questions at This Stage

Variables or scripting for a big job?

If it is "same layout, changing content", Variables are faster to set up and need no code. The moment you need conditionals beyond show/hide, calculations, external lookups, or per-file logic, a script is the right tool. They also combine — export data sets, then script the post-processing.

Do I have to learn to code to be a pro?

No — but being able to read and adapt a snippet dramatically expands what you can automate. Treat scripting like OpenType or LUTs: one more tool you reach for when it fits, not a separate career.
