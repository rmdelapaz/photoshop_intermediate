🖼️ Canvas Diagram QA Checker

Serve your course over HTTP (e.g. python3 -m http.server) and open this page from the same origin. It discovers every lesson from /index.html, loads each in a sandboxed iframe with the canvas API instrumented, and flags text that overflows its box/canvas or overlaps other text — the two failure modes of hand-coded <canvas> diagrams. The classic cause is ctx.textAlign='center' set once and reused for left-positioned bullets/code (they then spill left).

⚠️ Verify hits visually before fixing. Canvases that use translate/rotate are skipped (their coordinates aren't measurable statically). Diagrams whose visual box is a drawn path (pillars, houses) rather than a fillRect can false-positive, and overflows ≤5px are usually font-metric noise. This tool finds candidates; your eyes confirm them.
