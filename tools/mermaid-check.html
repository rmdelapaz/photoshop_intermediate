🧜 Mermaid Diagram QA Checker

Serve your course over HTTP (e.g. python3 -m http.server) and open this page from the same origin. It discovers every lesson from /index.html, then runs Mermaid's real parser on every .mermaid block and lists any that would fail to render. This is the reliable way to catch diagram breakers (a static text scan can't run the parser). Default breakers: unquoted labels containing (), &&/||/??, < >, a leading /, or ()/[]/quotes inside -->|edge labels|. Fix by quoting the label, e.g. A["Text (x)"] and -->|"next(err)"|.
