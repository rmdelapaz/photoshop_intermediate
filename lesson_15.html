Module 5 • Lesson 3📣 Campaign from One Master

The Module 5 deliverable. A real brief is never one image — it's a poster, an Instagram square, a story, and a web banner, all on-brand and due together. You will build them from a single master using artboards, linked Smart Objects, and multi-size export, so the set stays consistent and updates as one.

📚 What You'll Learn

By the end of this lesson, you will be able to:

  • Use artboards to hold multiple sizes in one document
  • Share art across artboards with linked Smart Objects
  • Adapt one design to portrait, square, and landscape without redrawing it
  • Export every artboard at once with Export As and presets
  • Deliver a coherent, on-brand campaign set from one file

⏱️ Estimated Time: 60 minutes

🎯 Project (Module 5 deliverable): One master file that outputs a full campaign — poster, IG square, story, and banner — all sharing type, art, and grade, all exportable in one pass.

👤 The Goal: One Idea, Every Size

One campaign idea, four deliverables. On the right, the slow way: four separate files, each edited by hand, drifting out of sync. On the left, one master with four artboards fed by shared linked art — change the key art or the logo once and all four stay in sync. Drag the handle:

🧠 Mental Model: Master & Instances

Think of one master that owns the campaign's shared truth — the key art, the logo, the tagline, the grade — and several instances (the artboards) that each present that truth at a specific size and crop. The shared art (key art, logo) is placed as linked Smart Objects, so it exists once and appears everywhere, and the shared type runs on the same named styles; only layout and framing differ per instance.

This is the same idea as 5.1's styles and 5.2's templates, scaled up to a whole deliverable set: decide the shared things once, place them by reference, and let each size be a view onto the same source rather than a fresh copy of it.

🗂️ Artboards & Multi-Size Export

Artboards are independent canvases inside one PSD, each with its own size (the New Document dialog and the Artboard tool's options bar offer preset sizes). You lay out each artboard, then File ▸ Export ▸ Export As renders every artboard to its own file in one pass — pick format, scale, and even multiple scales (1×, 2×) at once. One command, the whole set out the door.

⚠️ Design at the biggest size, export down

Build the key art at (or above) the largest deliverable's resolution — usually the print poster — and let smaller sizes scale down from it. Scaling a small master up for print softens everything. Biggest first, always.

One more limit: every artboard in a document shares one color mode and one resolution (ppi) setting. Keep the master in RGB for the screen sizes, and make the print poster's CMYK conversion a separate, final step on an exported copy (or its own file) when the printer asks for CMYK.

↔️ Reflowing a Design to Fit

The same idea has to survive a tall story (9:16), a square, and a wide banner (3:1). Don't just squash it — re-compose. Keep the focal point and the shared elements, but let the layout breathe differently in each frame: stack elements vertically for the story, center for the square, spread horizontally for the banner.

  • Anchor the focal point (logo, hero, headline) first in each frame, then arrange the rest around it.
  • Reuse, don't recreate: the linked art and named styles come along; only position and size change.
  • Protect safe zones: keep text clear of a story's UI overlays and a banner's crop edges.

✅ One idea, three compositions

A campaign feels cohesive when every size is clearly the same idea, not literally the same crop. Recomposing per aspect ratio — while the art, type, and grade stay shared — is exactly that balance.

🛠️ Guided Build: The Campaign

Bring your key art (ideally a Module 4 composite), your 5.1 type styles (copy a styled text layer in and its styles come with it), and your logo saved as its own file at the end of 5.2.

Step 1: Set up artboards · 10 min

  1. New document (RGB), Artboard on. Add artboards for a poster, IG square (1080²), story (1080×1920), and banner (1500×500), using presets where they exist and custom sizes otherwise.
  2. Design the poster (largest) at full resolution first.

Step 2: Share the essentials · 12 min

  1. Place Linked the logo and key art into each artboard so they're the same source everywhere.
  2. Apply your Paragraph Styles to each headline/subhead so the type voice is identical across sizes.

Step 3: Recompose per size · 14 min

  1. On each artboard, anchor the focal point, then rearrange around the aspect ratio. Respect safe zones on the story and banner.
  2. Optional: keep color shared by putting the same grade at the top of each artboard: duplicate the adjustment layer into each one, or load the same LUT you saved in Module 4 into a Color Lookup layer on each. Adjustment layers can't be linked, so if the look changes, update each copy (or re-export the LUT and reload it).

Step 4: Export the set · 8 min

  1. File ▸ Export ▸ Export As, select all artboards, choose format and scale, and click Export. (File ▸ Export ▸ Artboards to Files is an alternative for batch output.)
  2. Open the linked logo or key art file, make a visible change, and save it. Back in the master, every artboard updates (if one doesn't, use Layer ▸ Smart Objects ▸ Update All Modified Content). Re-export to prove the whole set updates from one edit.
  3. Save the master PSD with its linked files in the same project folder. Module 5 deliverable done. 🏆

✅ Project Completion Checklist (Module 5 deliverable)

  • ☐ One master PSD with poster, square, story, and banner artboards
  • ☐ Logo & key art placed as linked Smart Objects (shared source)
  • ☐ Type driven by the 5.1 Paragraph/Character Styles
  • ☐ Each size recomposed for its aspect ratio, safe zones respected
  • ☐ All artboards exported in one pass via Export As
  • ☐ A single source edit updates the whole set

🧗 Now You: Solo Variation

🌟 Your challenge

  1. Extend the campaign with two more sizes (a billboard and an email header) without recreating any shared element.
  2. Produce a light and a dark variant of the whole set by swapping one linked background — everything else stays put.
  3. Hand the project to a "client" (a friend): Package it, have them change the linked logo, and confirm every artboard updates on their machine.

Going further: pair this with data-driven graphics (a taste of Module 6) to spin out dozens of localized versions — same layout, different text and image per row of a data set.

🍳 Recipe Card: Campaign Set

One master, every size

  1. Artboards for each size; design the largest first
  2. Place Linked logo + key art into every artboard
  3. Apply shared Paragraph Styles for one type voice
  4. Recompose per aspect ratio; respect safe zones
  5. Export As all artboards at once (format + scale)

Mantra: share the idea, reframe the layout, export the set in one breath.

📝 Module 5 Summary

❓ Common Questions at This Stage

Isn't this really an Illustrator/InDesign job?

For vector-heavy branding and long documents, yes. But image-led campaigns — anything built on photography or composites — live in Photoshop, and artboards plus linked Smart Objects make it a genuinely capable production tool for that work.

How do I keep a big multi-artboard file manageable?

Lean on linked assets (keep data external), name layers and groups, and use layer color labels per artboard. If a file gets unwieldy, split shared art into its own linked PSD so each campaign file stays light.
