Module 7 • Lesson 1🏔️ Panoramas, HDR & Focus Stacking

A single frame is limited: only so wide, only so much dynamic range, only so much in focus. The fix for all three is the same idea — shoot several frames and let Photoshop align and blend them into one image no single exposure could capture.

📚 What You'll Learn

By the end of this lesson, you will be able to:

  • Shoot overlapping frames and stitch a panorama with Photomerge
  • Bracket exposures and combine them with Merge to HDR Pro for wider range
  • Shoot a focus series and focus-stack it with Auto-Align + Auto-Blend
  • See the shared engine — auto-align then blend — behind all three
  • Clean the seams, ghosts, and edges these merges leave behind

⏱️ Estimated Time: 55 minutes

🎯 Project: One stitched panorama, one HDR merge, and one focus stack — each cleaned up so the join is invisible.

🧠 Mental Model: Align, Then Blend

Every multi-shot technique is two steps. Auto-Align finds common detail across the frames and warps them into perfect registration, correcting for the small shifts, rotations, and lens distortion between shots. Blend then chooses, per pixel, the best contribution from the aligned stack — the overlapping edge for a panorama, the well-exposed tone for HDR, the sharpest region for a focus stack.

Because the engine is shared, the shooting discipline is shared too: keep the camera as steady and consistent as you can, overlap generously, and change only the one variable the technique needs (angle for pano, shutter for HDR, focus for stacking). Everything else held constant makes the align-and-blend clean.

🧰 Photomerge, HDR Pro & Auto-Blend

Each technique has a front door. File ▸ Automate ▸ Photomerge stitches panoramas (with layout options and a "Content-Aware Fill Transparent Areas" tick for the ragged edges). File ▸ Automate ▸ Merge to HDR Pro fuses an exposure bracket into a 32-bit file you then tone-map. For focus stacking you load frames as a stack, Edit ▸ Auto-Align Layers, then Edit ▸ Auto-Blend Layers ▸ Stack Images.

⚠️ Garbage frames in, garbage merge out

These tools can't invent detail that isn't in the frames. Too little overlap and a panorama won't stitch; a moving subject mid-bracket leaves HDR ghosts; a focus series that skips a distance leaves a soft band. Shoot the source carefully and the merge is nearly automatic.

✅ Shoot on a tripod when you can

Auto-Align is remarkable, but a tripod (and a 2-second timer) removes the frame-to-frame movement that causes ghosts and soft edges — especially for HDR and focus stacking, where the frames must register to the pixel.

🛠️ Guided Build: Merge Three Ways

Gather three small frame sets: an overlapping pan, an exposure bracket (−2 / 0 / +2), and a focus series of a close subject.

Step 1: Panorama · 10 min

  1. File ▸ Automate ▸ Photomerge, add the pan frames, Layout Auto, tick Blend + Content-Aware Fill Transparent Areas.
  2. Crop or accept the filled edges; heal any obvious stitch artifact.

Step 2: HDR · 12 min

  1. File ▸ Automate ▸ Merge to HDR Pro, add the bracket, tick Remove Ghosts if anything moved.
  2. Tone-map to taste (keep it believable), or output 32-bit and grade with Camera Raw.

Step 3: Focus stack · 10 min

  1. File ▸ Scripts ▸ Load Files into Stack (tick Attempt to Automatically Align).
  2. Select all layers, Edit ▸ Auto-Blend Layers ▸ Stack Images with seamless tones. Mask-fix any soft patch.

Step 4: Clean the joins · 6 min

  1. Zoom to 100% on each result and heal seams, ghosts, or soft bands.
  2. Apply a Module 4 unifying grade so all three feel like your work. 🏆

✅ Project Completion Checklist

  • ☐ A stitched panorama with invisible seams
  • ☐ An HDR merge with recovered highlights and shadows, no ghosts
  • ☐ A focus stack sharp front-to-back
  • ☐ Edges cropped/filled, joins healed at 100%
  • ☐ A consistent grade across all three

🧗 Now You: Solo Variation

🌟 Your challenge

  1. Shoot a vertical panorama (a tall building or waterfall) — the same technique, rotated 90°.
  2. Make a subtle HDR and a deliberately overcooked one; learn the line where recovered range tips into fake.
  3. Focus-stack a small object (a flower, a watch) from front to back and compare it to a single f/8 frame. The depth gain is the payoff.

Going further: combine techniques — a bracketed panorama (HDR each position, then stitch) for a high-range wide vista. It is exactly the same engine run twice.

🍳 Recipe Card: Multi-Shot Merge

Shoot many, blend to one

  1. Panorama: Photomerge (Auto + Blend + Content-Aware edges)
  2. HDR: Merge to HDR Pro (bracket, Remove Ghosts, tone-map)
  3. Focus stack: Load into Stack → Auto-Align → Auto-Blend (Stack Images)
  4. Overlap generously; change only the one intended variable
  5. Heal seams/ghosts at 100%, then one shared grade

Mantra: align first, blend second, and one careful shoot beats any repair.

Is HDR the same as the "HDR look" on phones?

Related but not identical. Phones auto-merge a bracket instantly; desktop Merge to HDR Pro gives you a true 32-bit file and full control over the tone-map, so you decide between natural range recovery and the stylized look.

My panorama bows or bends. What happened?

Wide pans on a flat projection curve straight lines. Try a different Photomerge layout (Cylindrical or Spherical), keep the horizon centered while shooting, and finish with Adaptive Wide Angle (Filter menu) to straighten.
