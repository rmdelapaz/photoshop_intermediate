# Labs

All hands-on lab materials for the course, grouped by module (one module per
session). Each module folder has its own README with the exact files and steps; this
is the map.

```
labs/
├─ build_practice_files.py   regenerates every module-N/practice/ and instructor/ folder
├─ module-1/   S1 · Advanced Selection & Masking: luminosity masks, channel masks & Blend-If, the hard cutout
├─ module-2/   S2 · Color & Tone, Deep: color pipeline, grading & LUTs, match, split-tone & soft-proof
├─ module-3/   S3 · High-End Retouching: frequency separation, dodge & burn, eyes/teeth/hair finish
├─ module-4/   S4 · Commercial Compositing: perspective & scale, light & shadow, atmosphere & one grade
├─ module-5/   S5 · Design Systems & Type: type system, Smart-Object templates, campaign from one master
├─ module-6/   S6 · Generative + Automation: generative compositing, conditional Actions, data-driven cards
├─ module-7/   S7 · Multi-Shot Techniques: panorama, HDR, focus stack, timeline animation (+ capstone kickoff)
└─ module-8/   S8 · Capstone: brief & plan, studio, case study (backup briefs and presentation mockups)
```

Each `module-N/` holds that module's lab README, a `practice/` folder for learners, and
an `instructor/` folder. **Everything in `instructor/` is instructor-only** and must not
be handed out up front:

| File | What it's for |
|------|---------------|
| `module-1/instructor/l03-hair-cutout-reference.png` | Exact-alpha catch-up cutout for anyone whose L03 cutout fails |
| `module-2/instructor/l04-histogram-answers.txt` | Answers to the five-histogram diagnosis drill |
| `module-2/instructor/l05-teal-gold-fallback.cube` | A ready-made LUT for anyone whose own LUT export fails |
| `module-3/instructor/l07-flaw-map-INSTRUCTOR.png` · `l08-light-map-INSTRUCTOR.png` | Answer maps: blemishes, tone patches and keepers; dodge/burn zones |
| `module-4/instructor/l10-plaza-answer-overlay.jpg` · `l10-horizon-practice-answers.jpg` | Horizon, vanishing point and correct figure scale |
| `module-4/instructor/l12-key-visual-reference.jpg` | A finished key visual built from the practice files |
| `module-5/instructor/l13-system-layout-INSTRUCTOR.png` · `l15-campaign-reference-INSTRUCTOR.png` | Model results for the type-system and campaign labs |
| `module-6/instructor/l18-cards-broken.csv` · `l18-card-reference-ana.jpg` | A deliberately broken data set to debug; a correctly bound card |
| `module-7/instructor/l19-pano-reference.jpg` · `l19-stack-reference.jpg` · `l20-reference-loop.gif` | Model merges and loop |
| `module-8/instructor/l21-vague-brief-fixed.txt` | The L21 warm-up brief, rewritten properly |

Some `practice/` files are catch-up starts, safe to hand out but best offered only to
learners who fall behind: `module-3/practice/l08-portrait-clean-flat.jpg`,
`l09-portrait-sculpted.jpg`, and the Module 8 `l21-backup-*` briefs and assets.

## Practice file policy

- **Everything in `practice/` is synthetic:** generated by `build_practice_files.py`,
  not photographed and not stock. It ships with the kit and may be handed to enrolled
  learners under your license tier.
- **Never use the course website's `images/` folder** for labs or handouts. Those are
  Adobe Stock images licensed to the author for the website only; they are not
  licensed for redistribution.
- **Module 3 demos use the illustrated practice portrait, never a learner's face.**
- **Learners' own images come first.** Practice files guarantee everyone can finish
  every lab, but the course is designed around people's own work. The setup guide
  tells learners what to bring to which session.
- **Consent:** portraits for Module 3 (Session 3) must be of someone who agreed to be
  retouched and shown in class, or a self-portrait. No photos of strangers, and none of
  children.
- **Work on copies.** Learners keep originals untouched and save a layered 16-bit `.psd`
  master plus flat exports. For the Module 6 batch lab they batch a folder of
  **copies**, never their only originals.
- **Generative labs (Module 6)** need Photoshop 2025 or newer, a signed-in Adobe
  account, an internet connection, and generative credits. Keep a no-generative
  fallback ready (Content-Aware Fill, the Remove tool) for anyone whose account can't
  generate.
- **Special formats:** Module 2 ships a 16-bit TIFF and an image tagged with an Adobe
  RGB (1998)-compatible profile; Module 7's HDR brackets carry generated exposure data.
  The module READMEs explain what Photoshop may ask when these open.

## Regenerating the practice files

From the `instructor-kit/` folder:

```bash
python3 labs/build_practice_files.py              # all modules (about 90 s)
python3 labs/build_practice_files.py --module 4   # one module (repeatable)
```

This rebuilds every `labs/module-N/practice/` and `instructor/` folder: 129 files,
about 40 MB. Output is deterministic (same bytes every run). Check the script's header
for its Python dependencies (Pillow and numpy).

**How references work:** the facilitator guide, workbook, and answer key point to
paths like `labs/module-4/practice/`, relative to the `instructor-kit/` root (where the
combined hand-out books live). Open the whole `instructor-kit/` folder to keep those
pointers valid.

Do not hand lab **reference notes** from the answer key to learners before the
corresponding lab.
