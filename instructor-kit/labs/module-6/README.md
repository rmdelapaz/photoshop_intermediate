# Module 6 Labs: Generative + Automation, Advanced (Session 6)

Three labs, one per lesson. L16 (Generative for Compositing, Lesson 6.1) needs
**Photoshop 2025 or later, internet, an Adobe sign-in, and generative credits**;
L17 (Advanced Actions & Conditionals, 6.2) and L18 (Data-Driven Graphics &
Scripting, 6.3) are fully offline. L18 is the **Module 6 deliverable**: a folder of
personalized graphics rendered from one template and a CSV.

Learners work on **their own material** where possible and fall back to the
synthetic practice files below.

The course site's `images/` folder is Adobe Stock licensed to the author and is
**not** redistributable. Never copy it into a lab. All practice files here are
synthetic and are generated by `labs/build_practice_files.py` (module 6 part:
`labs/_parts/m6.py`).

## L16: Generative for Compositing

**Uses:** the learner's layered Module 4 composite (best), or `l16-cramped-scene.jpg`
+ `l16-pasted-subject.png`.

**Setup with the practice files:** open `l16-cramped-scene.jpg`, Save As
`l16-composite-working.psd`, File ▸ Place Embedded `l16-pasted-subject.png`, and
drag it hard against the right edge with the feet near the bottom (match
`l16-cramped-composite-preview.jpg`). Name the layer `subject`.

**Step pointers (lesson Steps 1–5):**
1. Hide `subject`. Crop tool, Fill: Generative Expand, drag edges outward, commit,
   empty prompt, Generate. Audit the seams at 100%.
2. Lasso the SALE sign, its post, **and its cast shadow**, with margin. Generative
   Fill, empty prompt.
3. Small, flat selection on the gravel under and left of the feet (sun is on the
   right). Prompt `gravel with small shadows`. Mask the result.
4. Select `subject` → Harmonize (contextual task bar or Properties panel). Compare,
   keep the best, mask back edges and the face.
5. Grain + sharpening on generated areas, dodge & burn, one unifying grade.

**Now You:** `l16-three-distractions.jpg` has a notice sign (easy), a passer-by
(harder), and a hard diagonal shadow across the wall **and** the bicycle (hardest:
the fill has to rebuild the red frame and the wheel under the shadow). Also: the
same fill generated five times; a snapshot to a wide banner.

**Offline fallback:** Crop outward with Fill: Content-Aware Fill; Remove tool or
Content-Aware Fill (Output To: New Layer); a painted contact shadow (Lesson 4.2,
L11 Step 2); the L11 hand light-match (clipped 50% gray Dodge & Burn + clipped Color
Balance or Photo Filter) instead of Harmonize.

**Ethics:** do not run generative edits on photos of identifiable people without
their permission. For documentary or journalistic images, generative changes may be
off-limits; disclose edits when integrity matters. For client work, check which model
generated the result (Firefly or a partner model) and its terms.

## L17: Advanced Actions & Conditionals

**Uses:** a **copy** of `l17-input/` (or the learner's own mixed folder of copies),
`l17-watermark.png` kept outside the input folder, and an empty `l17-output/`.

**Step pointers:**
1. Record `Web Delivery` in set `Delivery` on `l17-delivery-01.jpg`: Fit Image
   2000 × 2000 px, Unsharp Mask (80% / 1.0 / 0), Place `l17-watermark.png`, Layer ▸
   Flatten Image, Save As JPG quality 10 into `l17-output/`. Stop. (Without the
   Flatten step, Save As won't offer JPEG.)
2. Preferences ▸ Units & Rulers ▸ Percent. Record `Crop Wide` (on 01, e.g. a 16:9
   crop) and `Crop Tall` (on 02, e.g. a 4:5 crop). Select Web Delivery's first step,
   Insert Conditional: If Document Is Landscape → Crop Wide, else Crop Tall. Drag the
   conditional to the top.
3. Batch: Source `l17-input/`, Destination `l17-output/`, Override Action "Save As"
   Commands, both Suppress options, Log Errors To File, Unsharp Mask dialog toggle off.
4. Create Droplet on the desktop; drag a folder onto it.
5. Set Units & Rulers back to Pixels.

**Now You:** three sizes into three subfolders (Batch Destination **None**); a
Document Has Layers conditional; a colleague-proof droplet with a Stop step.

## L18: Data-Driven Graphics & Scripting (Module 6 deliverable)

**Uses:** everything in `l18-data/`. The template **must be saved in `l18-data/`**
(same folder as the CSV and the photos) so the bare file names in the `photo` column
resolve.

**Step pointers:**
- Build the template: open `l18-card-background.jpg`, Save As `l18-card-template.psd`
  in `l18-data/`. Bring in `l18-ana.jpg` as a **pixel** layer filling the white
  window (both are 800 × 800 px; if placed as a Smart Object, Layer ▸ Rasterize ▸
  Smart Object). Add a type layer "Ana" in the name band and place
  `l18-sale-badge.png` at the photo's top-right corner.
1. Rename layers `name`, `photo`, `sale`.
2. Image ▸ Variables ▸ Define: Text Replacement on `name`, Pixel Replacement on
   `photo` (method Fit), Visibility on `sale`; variable names identical to the
   headers.
3. Data Sets… ▸ Import `l18-cards.csv`, tick Use First Column For Data Set Names,
   Preview on, step through rows.
4. File ▸ Export ▸ Data Sets as Files → `l18-cards-out/`, File Naming: Data Set Name.
   Six PSDs.

**Optional finish:** to flatten the cards to JPG, do **not** run the L17 Web
Delivery Action unchanged (its conditional would crop the portrait cards and Fit
Image would enlarge them). Duplicate it, delete the conditional and Fit Image steps,
keep a Flatten before Save As; or use File ▸ Scripts ▸ Image Processor.

**Script:** run `l18-resize-folder.jsx` with File ▸ Scripts ▸ Browse on
`script-test/` (a copy). It writes `web_*.jpg` into the same folder, so a second run
also processes those, which is exactly the "skip files already starting with `web_`"
challenge. With rulers still in Percent from L17, the script's size math can go
wrong; set Units & Rulers to Pixels first.

**Consent:** for the "20 social cards for a real list" challenge, learners use
names and photos only with the people's permission, or invented names with the
practice photos.

## Learners' own material: what to bring

Ask learners (in the Session 5 wrap-up) to bring:
- **L16:** their **layered** Module 4 composite (the PSD, not a flattened JPG), or any
  cramped, busy photo with a distraction; ideally a phone snapshot for the banner
  challenge.
- **L17:** a folder of **8 to 12 photos, mixed landscape and portrait, as copies**;
  optionally their own watermark or logo as a transparent PNG.
- **L18:** a **short real list** (team roster, event lineup, product list) as a
  spreadsheet, plus matching photos they have permission to use.

No material of their own? The practice files cover every step. Free-license photo
sources (Pexels, Unsplash) are fine after checking the license on each image.

## Practice file specs (for the generator script)

All JPEGs: RGB, sRGB ICC profile embedded, 72 ppi metadata, no EXIF. "Noise" means
per-pixel Gaussian noise, same value on R, G, B (mono), clipped to 0–255. All output
is deterministic (seeded by file name).

### L16

**`l16-cramped-scene.jpg`**: 1500 × 1200, quality 90. A late-afternoon plaza framed
too tight.
- Sky: vertical gradient to the horizon at y 610, `#86acd4` → `#e9c9a0` → `#f3d6aa`,
  with a warm `#fff0cc` glow bleeding in from **off-frame right** (the sun's side).
- Distant buildings: a row of flat `#c9a283` blocks with `#8e6f5c` windows between
  y ≈ 360 and the horizon, running off **both** edges, warmed toward the right.
- Low stone wall y 600–680 across the full width, lighter cap, vertical joints every
  95 px (the joints are the easiest place to spot a repeat after expanding).
- Gravel plaza from y 680 down: gradient `#bfa688` → `#d7bf9c`, mono noise sigma 7,
  and ~5,200 pebbles whose size grows toward the viewer.
- A lamppost jammed against the left edge (cramped framing), shadow toward lower left.
- **The distraction:** a SALE sign (white board, red border and red "SALE") on a brown
  post at x ≈ 850–1090, y 505–905, with a soft cast shadow falling to the lower left.
- The right third (x > 1130) is left open for the subject.
- Warm grade, mono noise sigma 2.6.

**`l16-pasted-subject.png`**: 340 × 880 RGBA, transparent background. A simple
standing figure (orange jacket, blue jeans, dark hair) deliberately **mismatched**
to the scene: lit from the **left** (bright left side, dark right side), a cold blue
cast, punchier contrast, crisp anti-aliased edges, no grain, no shadow. Everything
Harmonize (or the L11 hand match) has to fix.

**`l16-cramped-composite-preview.jpg`**: the scene with the subject composited at
x 1135, y 262 (feet at y ≈ 1130, 30 px from the right edge). Reference for
placement only; learners build their own from the two parts.

**`l16-three-distractions.jpg`**: 1800 × 1200, quality 90. Sky over a cream plaster
wall (y 230–860, textured), gray paving below with joints every 160 px. Subject: a
red bicycle leaning at the wall (x ≈ 630–1220). Distractions: (1) a blue "NOTICE"
sign on the wall at the right; (2) a dark passer-by silhouette at the left with a
short shadow; (3) a hard diagonal shadow band (a pole out of frame) crossing the wall
**and the bicycle**, darkening by 42%, kept off the sky. Mono noise sigma 2.2.

## Running the labs

**L16: Harmonize a Composite.** `l16-composite-working.psd`: room, removal,
connective tissue, Harmonize, finish by hand. Save layered.
**L17: A Delivery Action.** Record, add the conditional, drag it to the top, Batch
`l17-input/` → `l17-output/`, Create Droplet, reset rulers.
**L18: A Data-Driven Batch.** Template in `l18-data/`, three variables, import the
CSV, proof, Data Sets as Files. Then read and run the script on a copy.

**No credits or no network?** Follow the fallback in the facilitator guide: teach
L17 and L18 first, pair learners on shared credits, or do L16's jobs offline.
