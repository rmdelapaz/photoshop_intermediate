# Module 7 Labs: Multi-Shot Techniques (Session 7)

Two labs, one per lesson, plus the capstone kickoff (Lesson 8.1, L21), which needs no
practice files. L19 merges three small frame sets; L20 animates a layered design. Learners
work on the **practice sets in class** (they merge in seconds) and on **their own
full-resolution shoots at home**.

redistributable. Never copy it into a lab. All practice files here are synthetic and are

## Running the labs

**L19: Merge Three Ways** (Lesson 7.1). Suggested working names: `pano-working.psd`,
`hdr-working.psd`, `stack-working.psd` (the lesson does not name them).
1. **Panorama.** File ▸ Automate ▸ Photomerge → Browse → the four files in `l19-pano/`.
   Layout **Auto**; tick **Blend Images Together** and **Content Aware Fill Transparent
   Areas**. Crop or accept the filled edges; heal any stitch artifact at 100%.
2. **HDR.** File ▸ Automate ▸ Merge to HDR Pro → Browse → the three files in `l19-hdr/`.
   Tick **Remove Ghosts** (a bird crosses the window between frames). Mode **16 Bit** and
   tone-map in the dialog (keep it believable), or **32 Bit** to keep the range and
   tone-map later with Camera Raw.
3. **Focus stack.** File ▸ Scripts ▸ Load Files into Stack → the four files in
   `l19-stack/`, tick **Attempt to Automatically Align Source Images**. Select all layers,
   Edit ▸ Auto-Blend Layers… → **Stack Images**, tick **Seamless Tones and Colors**.
4. **Clean the joins** at 100% and apply one Module 4 unifying grade to all three.

**L20: A Looping Animation** (Lesson 7.2). Suggested names: `loop-working.psd`, `loop.gif`,
`loop.mp4`.
1. File ▸ Scripts ▸ Load Files into Stack → the three files in `l20-anim/` (all
   1080 × 1080, so they stack in register). Order them background, badge, headline
   (bottom to top). Convert the badge to a Smart Object.
2. Window ▸ Timeline → **Create Video Timeline**; panel menu ▸ Set Timeline Frame Rate ▸
   24 fps; trim every layer bar and the work area to 3 s.
3. Keyframe the badge's **Transform** (small → full size) and the headline's **Opacity**
   (0 → 100) and **Position** (a small rise). Hold, then return every layer to its
   frame-0 state by the last frame. Add near-the-end keyframes to fake an ease.
4. File ▸ Export ▸ Save for Web (Legacy) → GIF, Looping Options **Forever** (reduce the
   Image Size in the same dialog if the GIF is heavy). File ▸ Export ▸ Render Video →
   H.264. The practice design is square, so keep Size at **Document Size**, as the lesson
   says for non-16:9 designs.

**L20 Now You: cinemagraph.** Load the six `l20-steam/` frames into a stack, switch the
Timeline to **Create Frame Animation**, panel menu ▸ **Make Frames From Layers**, set
short frame delays and Looping **Forever**. The frames are identical except for the
rising steam (which completes one cycle over the six frames, so the loop is seamless);
for a true cinemagraph, mask the upper layers so only the steam area changes.

**Capstone kickoff (L21).** No practice files. Learners write on the **L21 pages of the
Module 8 workbook** (print them before the session). See the Module 8 lab README for
capstone assets.

## HDR metadata: if Photoshop asks for "Manually Set EV"

Merge to HDR Pro reads each frame's exposure from its metadata. The three practice frames
carry **generated** exposure data (they are not real camera files):

| File | Shutter | Aperture | ISO | Exposure bias |
|---|---|---|---|---|
| `l19-hdr-1-minus2ev.jpg` | 1/250 s | f/8 | 100 | −2 EV (darkest) |
| `l19-hdr-2-0ev.jpg` | 1/60 s | f/8 | 100 | 0 EV |
| `l19-hdr-3-plus2ev.jpg` | 1/15 s | f/8 | 100 | +2 EV (brightest) |

Normally the merge runs without questions. If a learner's copy has lost its metadata
(some cloud-sync tools, messaging apps, and "optimize images" utilities strip it), Photoshop
opens a **Manually Set EV** dialog and asks for the exposure of each image in turn.
Choose the option to enter **exposure time, f-stop, and ISO** rather than a bare EV number,
and enter the values in the table above: f/8 and ISO 100 for all three, and **1/250 s for
the darkest frame, 1/60 s for the middle, 1/15 s for the brightest.** This is the least
error-prone route, because "longer shutter = brighter frame" needs no sign convention. If
the merged preview looks inside-out (window dark, room blown out), the values were entered
against the wrong frames: cancel and re-enter them.

Learners bracketing on their own cameras won't see this dialog (the camera writes the
metadata). Some phone apps strip it; the same manual entry fixes it using the settings
the learner shot with.

## Learners' own material: what to bring

Ask learners (in the Session 6 wrap-up) to bring, **optionally**, one or more small sets
of their own for the L19 "Now You" (done at home):
- **Pano:** 3 or more frames of a wide view, turning on the spot, overlapping about 30%,
  exposure locked if the camera allows it. A vertical pano (tall building, waterfall) is
  the lesson's first challenge.
- **HDR:** a bracket of a high-contrast scene (a bright window from inside, a sunset with a
  dark foreground): −2 / 0 / +2, on a tripod or braced, with nothing moving.
- **Focus stack:** a small object (a flower, a watch) shot 3 to 5 times with focus stepped
  evenly from front to back. On a phone, tap to focus at each distance.

For L20: a simple **layered design** of their own (a logo, a badge, a headline); the Module
5 campaign master is ideal.

For the kickoff: **one or two capstone ideas** and a handful of reference images (their own
photos, or references from anywhere, since a moodboard is for direction, not for use in
the final piece). Capstone source assets must be their own photos or stock whose license
and credit terms they have checked.

Consent: if a learner's capstone or cinemagraph features an identifiable person, they need
that person's permission, as in Module 3.

## Practice file specs (for the generator script)

All JPEGs: RGB, 8-bit, sRGB ICC profile embedded, 72 ppi metadata, no EXIF unless stated.
"Noise" means per-pixel Gaussian noise (sigma given, same value on R, G, B) added after
drawing. Output is deterministic (fixed seeds per file). Total size about 5.5 MB.

### L19 panorama: `l19-pano/l19-pano-01.jpg` … `04.jpg`

Four 1800 × 1200 frames, quality 88, cut from **one** wide synthetic lake scene as if a
camera had been turned on a tripod head.
- **Scene:** drawn on a cylinder about 5,100 × 1,320 px (≈156° of view): a blue sky
  gradient with a sun glow, seven distinct cumulus clouds, a snow-capped mountain range
  with one signature peak, forested hills with pine silhouettes, a far shoreline with a
  **red cabin**, a **red-and-white striped lighthouse** on a rocky point, a **sailboat**
  and a **wooden pier**, a lake with blurred mirror reflections and ripple streaks, and a
  foreground shore of grass and boulders. Features are placed so each of the three
  overlap zones contains something distinctive (cabin, lighthouse, sailboat and pier).
- **Projection:** each frame is a rectilinear (normal-lens) view of the cylinder:
  focal length 1800 px (53° horizontal field), frames 34.5° apart, so neighbors
  **overlap by 35%**. Because it is a true re-projection, off-center lines curve slightly,
  as in a real pan, and Photomerge's projections (Auto, Cylindrical, Spherical) behave
  realistically.
- **Hand-held imperfections, so blending matters:** per-frame brightness gain 1.00 /
  0.93 / 1.07 / 0.96, corner vignetting of 22–30%, a slight color shift (±2% per channel),
  roll of 0 / 0.35 / −0.25 / 0.15°, and a vertical tilt offset of 0 / 12 / −9 / 5 px.
  Noise sigma 2.2, different per frame.
- **Instructor reference:** `instructor/l19-pano-reference.jpg`, the unprojected scene
  downscaled to 2400 px wide.

### L19 HDR bracket: `l19-hdr/…`

Three 1800 × 1200 frames, quality 90, with **generated EXIF** (see the table above).
- **Scene** (rendered in linear light, then "photographed"): a dim room with a sunlit
  window. Inside: warm walls darker toward the corners, a plank floor, a framed picture,
  a red armchair, a bookshelf with colored spines, and a potted plant silhouetted on the
  sill. Through the window: blue sky, three clouds, green hills and pine trees. A sunbeam
  in the window's shape (with mullion shadows) falls on the floor.
- **Range:** the interior is roughly 20 to 400 times darker than the window. Exposure scale 0.45 /
  1.8 / 7.2 (exactly two stops apart). Each frame goes through a camera-like curve (soft
  shoulder, then clipped) and the sRGB tone curve, so: the −2 frame holds the window and
  sky detail but the room is murky; the 0 frame has a blown window; the +2 frame shows the
  bookshelf and armchair clearly but the window and sunbeam are pure white.
- **Things to fix:** a small bird crosses the window at a different position in each frame
  (**Remove Ghosts** demo), and the camera shifts by up to 2 px between frames (**auto-align**).
  Signal-dependent noise is added in linear light, so the −2 frame's shadows are noisy,
  like a real underexposure.

### L19 focus stack: `l19-stack/…`

Four 1800 × 1200 frames, quality 90, of one tabletop scene, each focused at a different
depth.
- **Scene:** a green cutting mat in perspective (1 cm grid, heavier every 5 cm) receding to
  a striped back wall. A steel ruler runs along the depth axis, numbered 28–72 cm with
  millimeter ticks (the continuous sharpness gauge). Printed mat lettering at three depths.
  Objects at four depths: a big **red die** (near), a **daisy in a glass** (near-middle), a
  **blue mug** labelled "MID / zone 3 of 4" (middle), and **three books** with spine titles
  against the wall (far). The wall carries a "WALL CHART" with lines of letters and a line
  of fine print (far sharpness check).
- **Defocus:** depth is modeled from the table's perspective (inverse distance). Blur radius
  = 12 px × the depth difference from the focus plane; the table and wall use a blended
  blur stack, and each object is blurred as its own layer (so blurred edges spread
  naturally). Focus planes 0.10 / 0.37 / 0.64 / 0.92 of the depth range (file names `near`,
  `midnear`, `midfar`, `far`), spaced so the whole scene is covered with no soft band.
- **Focus breathing:** each frame is scaled 0.4% more than the last about the center, as
  real lenses do when refocusing, so **Auto-Align** has real work to do.
- **Teaching trick:** leave out frame 2 and the table between the die and the mug turns
  soft, the "skipped focus distance" band from the lesson's FAQ.
- Noise sigma 2.0, different per frame.
- **Instructor reference:** `instructor/l19-stack-reference.jpg`, the all-in-focus scene.

### L20 animation pieces: `l20-anim/…`

Three 1080 × 1080 files that stack in register (Load Files into Stack).
- **`l20-anim-1-background.jpg`** (quality 90): a warm coffee-brand poster background:

  soft glows, a thin cream inset frame 36 px from the edges, the brand line "NORTHSIDE
  COFFEE CO." top-left (a fictional brand), noise sigma 3. Upper right and the lower third
  are left clear for the animated pieces.
- **`l20-anim-2-badge.png`** (RGBA, transparent): a 16-point gold starburst `#f5b83d`,
  radius 175 px, centered at (800, 300), with a cream ring and a red disc reading "NEW /

- **`l20-anim-3-headline.png`** (RGBA, transparent): "FRESH ROAST" in bold cream (about

- **Instructor reference:** `instructor/l20-reference-loop.gif`, 540 × 540, 36 frames at
  12 fps (3 s), loop forever: the badge scales 20% → 100% with a slow finish, the headline
  fades in while rising 40 px, a hold, then both return to their frame-0 state.

### L20 cinemagraph frames: `l20-steam/l20-steam-01.jpg` … `06.jpg`

Six 960 × 720 frames, quality 90: a white cup of coffee on a wooden table against a dark
wall, lit from the left. Everything except the steam is drawn once with one fixed noise
pattern, so the frames differ **only** in the three rising steam wisps, whose phase
advances one sixth of a cycle per frame (frame 6 flows back into frame 1 seamlessly).
