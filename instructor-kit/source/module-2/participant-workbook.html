L04

Color Management & Working Spaces (2.1)

50 min
By the end you can
  • Explain working spaces (sRGB, Adobe RGB, ProPhoto) and pick the right one
  • Say why you edit in 16-bit and what banding actually is
  • Read the histogram and diagnose an image before touching a slider
  • Set up Photoshop's Color Settings once, correctly, for the rest of the course
Key ideas
  • An image is color in a container with two properties: how wide it is (the working space, or gamut) and how finely divided (the bit depth). 8-bit = 256 steps per channel; 16-bit = over 32,000.
  • Banding is what happens when an edit demands more tonal steps than the file has. 16-bit has about 128 times more steps, so gradients survive hard grading.
  • A number like "R 220" is meaningless without its container. Color management keeps track of the container so a color means the same thing from capture to screen to print.
  • Capture wide, edit wide and deep, convert down last. Never edit in the narrow export space.
  • Convert to Profile remaps the colors to fit the new space and keeps them looking right. Assign Profile just relabels the container and shifts your colors.
SpaceUse forNotes
sRGBWeb, social, most screens, emailThe safe default for anything online. Assume the internet is sRGB.
Adobe RGBPrint work, especially CMYKHolds the cyans and greens many printers can reproduce but sRGB clips.

Worked example: set up & diagnose
  1. Edit ▸ Color Settings. RGB working space: Adobe RGB (1998) for print-capable work (or sRGB if you are strictly web). CMYK: your print provider's press profile (for example Coated GRACoL 2006 or Coated FOGRA39) or the default. Policies: Preserve Embedded Profiles, mismatch warnings on (Ask When Opening).
  2. Open your image (or l04-smooth-sky-16bit.tif). Confirm the bit depth: Image ▸ Mode ▸ 16 Bits/Channel for anything you will grade hard.
  3. Window ▸ Histogram. Before any edit: crammed left (underexposed) or right (overexposed)? A spike against either wall (clipped, lost detail)? Narrow (flat, low contrast)? Write one sentence: what does the image need?
  4. Prove the container matters. Duplicate a smooth-gradient image; set one copy to 8-bit, keep the other 16-bit. Apply the same aggressive Curves to both, then a strong brighten. Zoom in: the 8-bit copy bands.
  5. Export correctly. Save the layered master (for example color-master.psd). For web: Image ▸ Duplicate (tick Duplicate Merged Layers Only), then on the copy Edit ▸ Convert to Profile ▸ sRGB, Image ▸ Mode ▸ 8 Bits/Channel, export. (File ▸ Export ▸ Export As can also convert to sRGB for you.)
Recipe card: Trustworthy color, start to finish
  1. Edit ▸ Color Settings: deliberate working space, Preserve Embedded Profiles
  2. Work in 16-bit for anything you will grade hard
  3. Read the histogram and name the problem before editing
  4. Keep the master wide + 16-bit
  5. Export: on a duplicate, Convert to Profile (sRGB for web) at the very end

Mantra: capture wide, edit deep, convert down last.

L05

Grading with Curves, Gradient Maps & LUTs (2.2)

60 min
By the end you can
  • Grade with per-channel Curves for precise color in shadows, mids and highlights
  • Use a Gradient Map to remap tones to a color ramp
  • Apply and save a LUT (Color Lookup) to reuse a grade consistently
  • Keep the whole grade non-destructive and dialable
Key ideas
  • Correcting asks "what is wrong?" Grading asks "what should it feel like?" Every grade is a remap: you decide what color each tone becomes.
  • Three remapping tools, from surgical to sweeping: per-channel Curves (the precision instrument), Gradient Map (map the whole tonal range to a ramp), LUT (a saved recipe of a finished grade).
  • Gradient Map: darkest pixels get the gradient's left color, brightest get its right color. Blend it, don't bake it: Color or Soft Light, opacity around 15–40%.
  • LUT (Look-Up Table, a .cube or .3dl file): "turn this input color into that output color," for every color. Apply one with a Color Lookup adjustment layer.
  • Correct, then grade, then bottle. Grading on top of a neutral base is what makes a look portable.
Worked example: grade & bottle it
  1. Open a portrait (or l05-portrait-studio.jpg) in your 2.1 pipeline: 16-bit, deliberate working space. Correct to a neutral base first (exposure and white balance) with a Curves layer or Filter ▸ Camera Raw Filter. Save As grade-working.psd.
  2. Contrast, then color. Curves layer: a gentle RGB S-curve. New Curves layer, Blue channel: lift the shadow end (blue shadows), drop the highlight end (warm, yellow highlights). For a truer teal, also lift Green slightly or drop Red slightly in the shadows.
  3. Gradient Map accent. Teal-to-gold ramp, layer set to Color or Soft Light, opacity about 20–30%.
  4. Refine locally. Mask a Curves or the Gradient Map layer so skin stays natural while the background goes moody. A luminosity mask (Lesson 1.1) keeps the grade out of the brightest highlights.
  5. Bottle it. Save grade-working.psd first. Disable the masks (Shift-click each mask thumbnail), hide anything that is not part of the grade, keep a Background layer plus adjustment layers, then File ▸ Export ▸ Color Lookup Tables → save a .cube. Re-enable the masks.
  6. Open a different photo (or l05-pier-dusk.jpg), add a Color Lookup layer, Load 3D LUT…, choose your .cube. Watch the whole look transfer.
Recipe card: Build a look and save it
  1. Curves: contrast (RGB S-curve) first
  2. Curves per channel: teal shadows, warm highlights (Blue channel split)
  3. Gradient Map (teal→gold) at ~20–30% / Color blend
  4. Mask locally (luminosity or subject masks)
  5. Save the master; disable masks, then File ▸ Export ▸ Color Lookup Tables → reuse as a .cube

Mantra: correct, then grade, then bottle.

L06

Match, Split-Tone & Soft-Proof (2.3)

55 min
By the end you can
  • Match color across two images so a set feels like one shoot
  • Refine a split-tone (warm highlights, cool shadows) with Color Balance / Curves
  • Soft-proof for a printer and read the gamut warning
  • Deliver a graded image as both a web file and a print-ready file
Key ideas
  • A split-tone puts one color into the shadows and a different (usually complementary) color into the highlights. The classic: cool shadows, warm highlights, mids roughly neutral so skin stays believable.
  • Color Balance has explicit Shadows / Midtones / Highlights buttons; per-channel Curves do the same by which end of the curve you bend.
  • Matching: sample a known neutral (or skin) in each image with the Color Sampler Tool, read the Info panel (Window ▸ Info), and move each Curves channel until the values meet. Match tones before colors: black point, white point, then mid color.
  • Soft-proofing simulates the print on screen: View ▸ Proof Setup ▸ Custom. Toggle proof with Ctrl/⌘ + Y; Gamut Warning (Ctrl/⌘ + Shift + Y) grays out colors the printer can't reproduce.
  • Neon dies on paper. Pull saturation down where the warning lights up, and the print matches the proof.

Worked example: split-tone & proof
  1. Open grade-working.psd from Lesson 2.2 (16-bit, wide space). If you graded a landscape there, drag your Lesson 2.2 grading layers onto a corrected portrait instead. Save As finish-working.psd.
  2. Split-tone. Add a Color Balance layer. Shadows: push toward cyan/blue a little. Highlights: toward red/yellow. Midtones: near neutral. Judge on skin: warmly lit, not sunburnt.
  3. Match a companion. Open a second photo of the same set (or l06-companion-portrait.jpg). Drop a Color Sampler on a comparable point in each. Add Curves to the second image and move each channel until its sampled values approach the first image's.
  4. Soft-proof. View ▸ Proof Setup ▸ Custom: printer profile (or SWOP v2), Relative Colorimetric or Perceptual, Black Point Compensation, Simulate Paper Color. Proof on (Ctrl/⌘ + Y). Gamut Warning on (Ctrl/⌘ + Shift + Y); lower the saturation of anything gray with a masked Hue/Saturation until it clears.
  5. Deliver both files. Save the layered master first. Web: Image ▸ Duplicate (Duplicate Merged Layers Only), Convert to Profile ▸ sRGB, 8 Bits/Channel, export a JPG. Print: another merged duplicate, Convert to Profile ▸ your printer/CMYK profile (or keep tagged RGB if your printer asks for it), save as PDF or TIFF.
Recipe card: Split-tone, match, and print-check
  1. Color Balance: cool shadows, warm highlights, neutral mids
  2. Match a companion image with Color Sampler + Curves (tones before colors)
  3. View ▸ Proof Setup ▸ Custom → printer profile, Rendering Intent + Black Point Compensation, Simulate Paper Color
  4. Gamut Warning (Ctrl/⌘ + Shift + Y) → desaturate flagged areas
  5. Deliver from duplicates: Convert to sRGB (web) and to the printer profile (print)

Mantra: what you see is only trustworthy once you have proofed it.
