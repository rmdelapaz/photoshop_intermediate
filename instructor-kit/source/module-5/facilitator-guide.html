Module 5: Design Systems & Type

How to teach the three lessons that turn one good design into a small production system: a type system built from a modular scale, named styles and a grid (L13), Smart-Object templates and linked assets that update themselves (L14), and a full campaign (poster, square, story, banner) from one master file (L15). This module opens the Commercial Work tier's production thinking: decide once, reuse everywhere.

3 lessons 3 hrs session incl. break Lessons L13–L15 Level Intermediate Maps to Session 5

How to Use This Guide

  • Same rhythm as every module: Frame → Demo → Guided build → Check. The lesson's "Now You" solo variation starts in class when there is time and finishes at home. Every lesson ends with a recipe card, a checklist and a journal prompt; use them as your closers.
  • One brand runs through the whole session. The practice files follow "Northwind · Coastal Coffee Roasters," the example from Lesson 5.1. The type styles from L13 and the logo from L14 feed the L15 campaign, so learners should keep everything in one project folder from the first minute.
  • Name the mindset shift. Modules 1–4 were about making one image excellent. Module 5 is about making decisions once and letting a system carry them: a style, a template, a linked file, a master. Say it out loud: "Today we stop editing things and start building things that edit themselves."
  • Teal = hands-on, amber = watch-outs. In this module the watch-outs are mostly structure problems: a linked file that moved, replacement art at the wrong size, text that "won't snap," a master built small and scaled up.
  • Shortcuts are given as Windows / Mac: Ctrl/⌘, Alt/⌥. Tool letters used today: Type T, Move / Artboard V, Rectangle U, Free Transform Ctrl/⌘+T, show grid Ctrl/⌘+'.
The #1 risk of Session 5: files that wander

Linked Smart Objects are the backbone of L14 and L15, and they break the moment a linked file is moved or renamed. Learners who save to the desktop, then "tidy up" into a folder, lose every link and lose the lesson's payoff. Start the session by having everyone create one project folder (suggested name northwind-campaign/) and copy l14-logo-v1.png into it as logo.png. Say: "Everything you make today lives in this folder, and nothing in it moves. The power of links comes with the discipline of not moving them." The second trap is Replace Contents with art of a different size: keep the practice designs at the placeholder's exact pixel size (the filenames say it: …-1200x1800.png).

Before Session 5

  • ☐ Copy labs/module-5/practice/ to each machine (or a shared drive). Keep labs/module-5/instructor/ (the two model results) for your screen only. Never hand out the course site's licensed images/ folder.
  • ☐ Remind learners (in the Session 4 wrap-up or by email) to bring: their Module 4 composite (the layered PSD, or a full-resolution export) as campaign key art; optionally their own logo as a transparent PNG; optionally a photo of a surface to brand (a mug, a poster on a wall, a laptop lid); and the LUT they saved in Module 4 if they want a shared grade. Details in labs/module-5/README.md.
  • ☐ Check every machine is signed in to Creative Cloud so Adobe Fonts can activate fonts (L13 pairs a display face and a text face). Activate two families on the demo machine in advance in case the network is slow.
  • ☐ Check the Photoshop version so menus match the lesson: in current versions the columns command is View ▸ Guides ▸ New Guide Layout (older versions: View ▸ New Guide Layout). Artboards, Place Linked and File ▸ Package are in every recent release.
  • ☐ Set your demo machine's Preferences ▸ Units & Rulers ▸ Type to Pixels (L13 Step 1), and know where Preferences ▸ Guides, Grid & Slices is on both platforms (Edit ▸ Preferences on Windows, Photoshop ▸ Settings/Preferences on Mac).
  • ☐ Open lesson_13.html, lesson_14.html and lesson_15.html in browser tabs for the before/after sliders, and have l13-ransom-note-before.png ready to project.

One story: decide the type once (styles) → decide the treatment once (templates) → decide the campaign once (a master with linked art). The through-line is the lesson mantra: make the decision once, name it, and let the system carry it everywhere.

Lesson Plans

L13

Type Systems, Styles & Grids (Lesson 5.1)

47 min
Objectives
  • Build a modular type scale and a clear hierarchy from it
  • Create and apply Paragraph and Character Styles so type is consistent and editable
  • Turn on real OpenType features: ligatures, true small caps, oldstyle figures
  • Set up columns and a baseline grid (Photoshop's document grid, spaced at your leading) so text sits on a shared rhythm
  • Pair typefaces from Adobe Fonts with intent, not by accident
Timing
3mFrame: one voice, not twenty (ransom note vs system)
4mMental model: the modular scale and the four levers
4mDemo: styles and real OpenType
4mDemo: columns plus a document grid at the body leading
2mDemo: edit one style, watch the page re-flow
26mGuided build: a type system (Steps 1–4)
4mSelf-check, recipe card, journal prompt
Teaching sequence & live-demo script
  1. Frame: one voice, not twenty (3m). Project l13-ransom-note-before.png, then the lesson's slider. Ask: "Count the fonts. Count the alignments." Say: "Same words, completely different credibility. The ransom note isn't ugly because of any one choice. It's ugly because nothing agrees with anything. A type system replaces 'eyeball each label' with decisions you make once and reuse everywhere."
  2. The modular scale (4m). Write on the board: base 16 × ratio 1.25. Multiply up and down: 13 / 16 / 20 / 25 / 31 / 39. Assign roles: Caption 13, Body 16, Subhead 20, H2 25, H1 31, Display 39. Say: "You never freehand a size again. The math guarantees any two sizes already agree." Then the four cheap levers: size, weight, color, space. Say: "Often a weight change or more space says 'this matters' more elegantly than making it bigger."
  3. Units first (part of Step 1). Preferences ▸ Units & Rulers ▸ Type ▸ Pixels. Say: "Photoshop measures type in points by default. We'll work in pixels like the lesson; if you keep points, use the same numbers as pt."
  4. Styles and OpenType (4m). Set one Body line: text face, 16 px, leading 24 px, tracking 0. Open the Character panel; show the OpenType buttons in the row at the bottom (also panel menu ▸ OpenType): Standard Ligatures, Oldstyle Figures, Small Caps. Type "fi fl" to show real ligatures. Then Window ▸ Paragraph Styles: with the line selected, create a new style from it and name it Body. Show Window ▸ Character Styles is a separate panel, for a word-level Emphasis or Link. Say: "A style bottles the whole spec: font, size, leading, tracking, color, OpenType. And never press Faux Bold or Faux Italic: they smear a regular weight. No real bold in the family? Pick another face."
  5. Columns plus a grid (4m). View ▸ Guides ▸ New Guide Layout (older versions: View ▸ New Guide Layout): 3 or 6 columns, a gutter, margins. Say: "That's columns and rows, not a baseline grid. Photoshop has no baseline-grid feature like InDesign's, and text never snaps its baselines to a grid." Then Preferences ▸ Guides, Grid & Slices: Gridline Every 24 px, Subdivisions 1. Show it with View ▸ Show ▸ Grid (Ctrl/⌘+'). Zoom in and nudge a text layer with the arrow keys until its first baseline sits on a gridline. Say: "Leading equals the grid, so once the first baseline is on a line, every line after it lands on the grid too. Snap To ▸ Grid snaps a layer's edges, not its baselines, so check by eye."
  6. Prove the system (2m). With a few styled blocks on the page, edit the Body style's size by one step. Everything re-flows. Say: "That propagation is the win. When the client says 'body a point bigger everywhere,' this is one edit, not forty."
Lab: A Type System (26 min)

Learners follow Steps 1–4 using the copy in labs/module-5/practice/l13-layout-copy.txt (Display, H1, Subhead, H2, Body, CTA, Caption). New document at a target size, two Adobe Fonts (one display, one text). The copy deck offers the lesson's numbers and, for an 1800 × 2400 px practice poster, the same scale ×3 (Body 48 on a 72 px grid). Save as a PSD (suggested: northwind-campaign/type-system.psd); its styles feed L15.

Definition of done (the lesson's checklist): a written modular scale with roles assigned; columns via New Guide Layout plus a document grid set to the body leading; Paragraph and Character Styles created and named; real OpenType on, no faux bold or italic; editing one style updates every instance.

Circulate for: text set by hand after the styles exist (the Paragraph Styles panel shows a "+" override next to the style name); a leading that isn't the grid increment or a multiple of it; Faux Bold toggled on; three or more families. Put labs/module-5/instructor/l13-system-layout-INSTRUCTOR.png on your screen as the model.

Mistakes to pre-empt
  • "My text won't snap to the grid." It never will: Photoshop has no true baseline grid. Keep leading equal to the grid increment, align each block's first baseline by eye, zoomed in.
  • Local overrides. Changing the size of styled text by hand breaks the link to the style. Clear the override (Paragraph Styles panel) and edit the style instead.
  • Points vs pixels confusion. Units & Rulers ▸ Type still on Points while the plan says px. Change the preference or use the same numbers as pt, consistently.
  • Faux styling. Faux Bold and Faux Italic distort letterforms. Real weight or a different face.
  • Typesetting a brochure. A paragraph or two on a poster, yes. Long, text-heavy documents belong in InDesign.
  • The ransom note again. Usually two families: one display, one text. Three is advanced; four is almost always the ransom note.
Check for understanding: self-check + journal

Answers: Q1 C) 13 / 16 / 20 / 25 / 31 / 39; Q2 A) edit the style once and every instance updates; Q3 D) Preferences ▸ Guides, Grid & Slices, Gridline Every = body leading, Subdivisions 1; Q4 B) Snap To Grid snaps layer edges, not baselines, so align the first baseline by eye; Q5 C) use a face that has a real Bold, not Faux Bold; Q6 A) columns and rows with gutters and margins, not a baseline grid. Full explanations in the Answer Key.

Journal (finish at home if needed): Find two typefaces you think pair well and articulate why — contrast in structure, shared era, matching x-height? Naming the reason turns taste into a repeatable skill.

Differentiation

Fast finishers (if time / homework): the lesson's solo variations: build the same layout with ratios 1.2 and 1.618 and compare the mood; restrict to one typeface and build hierarchy with weight and space only; rebuild an ugly flyer (or l13-ransom-note-before.png) on a scale and grid, keeping the content identical. Going further: audition a display + text pair in Adobe Fonts using the classification and property filters (x-height, contrast), then lock them into the styles.

Struggling learners: three roles only (Display, H1, Body), one grid, one column guide layout. The must-have is one named style edited once and seen updating everywhere. Hand them the recipe card and the copy deck's numbers so the math isn't a barrier.

L14

Smart-Object Templates & Linked Assets (Lesson 5.2)

45 min
Objectives
  • Explain what a Smart Object protects and why it is non-destructive
  • Choose between embedded and linked Smart Objects for a job
  • Build a mockup template with a warped Smart-Object placeholder
  • Use Replace Contents and Place Linked to swap art in one move
  • Update one linked file and have every design using it refresh
Timing
3mFrame: change once, update everywhere (lesson slider)
3mMental model: a container you can refill; embedded vs linked
7mDemo: placeholder, warp, Multiply/Screen, Replace Contents
3mDemo: a linked logo updating in two places; Package
25mGuided build: a reusable template (Steps 1–4)
4mSelf-check, recipe card, journal prompt
Teaching sequence & live-demo script
  1. Frame (3m). Lesson slider: one linked source feeding three deliverables vs three baked-in copies. Say: "A design you can only use once is a craft. A design that updates itself across ten files is a system. The linked model costs a little setup and repays it every time the art changes, which on real jobs is constantly."
  2. A container you can refill (3m). Say: "A Smart Object is a container. Scale it down and back up, it stays sharp. Filter it, the filter becomes a Smart Filter you can retune. Transforms, warps, filters and styles live on the container; Replace Contents swaps what's inside and keeps all of that." Then the catch: Say: "The container's transform is applied to whatever you swap in. Different pixel dimensions, different result. Build placeholders at the exact size of the art they'll hold." Embedded vs linked: embedded is stored inside the PSD, each copy independent; linked (File ▸ Place Linked) points at a file on disk that many documents share.
  3. Placeholder and warp (Steps 1, 3m). Open l14-mockup-poster-wall.jpg. Rectangle tool (U), click once on the canvas and enter 1200 × 1800 px, the exact size of the practice designs. Say: "Exact size of the art, not the size it looks on the wall. You size it to the surface next." Right-click the layer ▸ Convert to Smart Object. Ctrl/⌘+T, scale it down over the blank poster, then right-click ▸ Warp and drag the four corners onto the poster's corners (Perspective Warp also works).
  4. Light it (Step 2, 2m). Above the placeholder, a new layer set to Multiply; paint the poster's fold shadows and the window-bar shadow back over it (sample the dark from the photo). A new layer set to Screen for the lit fold ridges. Alt/⌥-click between each layer and the placeholder to clip it. Say: "Effects on the container and the layers around it, never baked into the art. The art stays a clean, swappable rectangle."
  5. Swap (Steps 3–4, 2m). Double-click the placeholder thumbnail: it opens in its own tab. Place l14-art-a-sunrise-1200x1800.png, save, close: it lands on the wall, warped and lit. Then Layer ▸ Smart Objects ▸ Replace Contents ▸ l14-art-b-geometric-1200x1800.png. Finally Replace Contents with l14-art-d-landscape-1800x1200.png and let the room see it come in wrong. Say: "Different shape, different result. For odd-sized art, double-click the placeholder and paste into its existing canvas instead." Undo.
  6. Linked logo (3m). New document (a quick "brand sheet"). File ▸ Place Linked ▸ northwind-campaign/logo.png; place it twice at different sizes. Point out the link badge in the Layers panel. Now update the source: open logo.png, change it (for example Image ▸ Adjustments ▸ Hue/Saturation on its single layer) and File ▸ Save; or, in the file manager, copy l14-logo-v2.png over logo.png. Back in the brand sheet, both placements refresh (if not: Layer ▸ Smart Objects ▸ Update All Modified Content). Then mention File ▸ Package: Say: "Package collects every linked file so nothing breaks on another machine. Move or rename a linked file and Photoshop loses it; the layer shows a warning, and Relink to File fixes it."
Lab: A Reusable Template (25 min)

Learners follow Steps 1–4 on l14-mockup-poster-wall.jpg (or their own surface photo; l14-mockup-tote-bag.jpg is the harder, curved alternative that genuinely needs Warp). Swap in at least two of the …-1200x1800.png designs, then prove the size trap with the landscape design. Save as a reusable template (suggested: northwind-campaign/mockup-template.psd) and make sure logo.png sits in the project folder for L15.

Definition of done (the lesson's checklist): the placeholder is a Smart Object, warped to the surface; shadows (Multiply) and highlights (Screen) on the container, clipped; art swaps via Replace Contents or double-click edit; shared art uses Place Linked where appropriate; saved as a reusable template, and Packaged if handing off.

Circulate for: a placeholder rasterized by accident (no Smart Object badge); shadow layers not clipped (they darken the wall too); a placeholder drawn at poster-on-screen size (about 600 × 900) so the art comes in at half size; the logo placed from Downloads instead of the project folder.

Mistakes to pre-empt
  • Treatment baked into the art. Warping or shadowing the design itself means the next design needs it all again. Treat the container.
  • Replacement art at the wrong size. The container's transform applies to new contents. Export art at the placeholder's exact pixel size, or paste into the existing canvas.
  • Moved or renamed linked files. The link breaks. Keep one project folder, don't reshuffle, Package before handoff.
  • Embedded when linked was meant. Place Embedded copies the art into the PSD; editing the original file changes nothing. Check for the link badge.
  • Expecting a PNG to keep layers. If they edit logo.png by adding layers, saving asks for another format. Change the single layer directly, or swap the file in the file manager.
Check for understanding: self-check + journal

Answers: Q1 B) they stay on the container and apply to the new art; Q2 D) a linked Smart Object points to one file on disk that many documents share; Q3 A) the container's transform is applied to art with different pixel dimensions; Q4 C) on Multiply and Screen layers above the placeholder, clipped to it; Q5 B) File ▸ Package; Q6 D) the link breaks and the layer shows a warning (Relink to File). Full explanations in the Answer Key.

Journal: Think of a repetitive design task you have done by hand. How would a Smart-Object template and a linked asset have collapsed it into a single edit?

Differentiation

Fast finishers (if time / homework): the lesson's solo variations: a three-surface mockup (front, side, angled; try the wall and the tote together) fed by one shared linked file; a "brand sheet" PSD with a linked logo, updated from the source and seen refreshing on reopen; a favorite filter turned into a Smart Filter and retuned later. Going further: nest Smart Objects so a whole sub-design, with its L13 type system, becomes one swappable unit.

Struggling learners: poster wall only, and Free Transform corners rather than Warp if Warp is fighting them (the poster is flat). One Multiply shadow layer, clipped. The must-haves are a Smart-Object placeholder and one successful Replace Contents.

L15

Campaign from One Master (Lesson 5.3)

60 min
Objectives
  • Use artboards to hold multiple sizes in one document
  • Share art across artboards with linked Smart Objects
  • Adapt one design to portrait, square and landscape without redrawing it
  • Export every artboard at once with Export As and presets
  • Deliver a coherent, on-brand campaign set from one file
Timing
3mFrame: one idea, every size (lesson slider)
4mMental model: master and instances; biggest first; one color mode
8mDemo: artboards, Place Linked, styles, recompose, Export As
38mGuided build: the campaign (Steps 1–4)
4mShowcase: one source edit, every artboard updates, re-export
3mSelf-check, recipe card, journal prompt
Teaching sequence & live-demo script
  1. Frame (3m). Lesson slider: four drifting files (poster_v3, insta_FINAL, banner_old, story_v2) vs one master with four artboards. Say: "A real brief is never one image. It's a poster, a square, a story and a banner, all on-brand and due together. Consistency stops being willpower and becomes structure."
  2. Master and instances (4m). Say: "The master owns the shared truth: key art, logo, tagline, grade. Each artboard is a view onto it at a specific size and crop. Same idea as 5.1's styles and 5.2's templates, scaled up." Two rules on the board: design at the biggest size, export down (usually the print poster), and every artboard shares one color mode and one resolution. Say: "Keep the master RGB. If the printer wants CMYK, that's a separate, final step on an exported copy."
  3. Artboards (Step 1, 2m). File ▸ New, RGB, Artboards ticked. Build the poster at 3300 × 5100 px (11 × 17 in at 300 ppi), then add IG square 1080 × 1080, story 1080 × 1920 and banner 1500 × 500 with the Artboard tool (under the Move tool) using its options-bar presets where they exist and custom sizes otherwise. Save as northwind-campaign/campaign-master.psd.
  4. Share the essentials (Step 2, 2m). Select the poster artboard, File ▸ Place Linked the logo and l15-key-art.png (or a Module 4 composite). Repeat for each artboard (or duplicate the linked layer with Ctrl/⌘+J and drag it onto the next artboard: a duplicate still points at the same file). Copy a styled text layer in from type-system.psd: its Paragraph Styles come with it. Say: "Placed by reference, not copied. It exists once and appears everywhere."
  5. Recompose, don't squash (Step 3, 2m). On the banner: anchor the focal point first (key art left), then headline and CTA spread to the right. On the story: stack vertically and keep text inside the safe zone (drop l15-safe-zones-story.png on top as a temporary guide, then delete it). Say: "Every size clearly the same idea, not literally the same crop."
  6. Export the set (Step 4, 2m). File ▸ Export ▸ Export As: every artboard is listed; pick format (PNG or JPG) and scale (1×; 2× if the platform wants it), Export. Mention File ▸ Export ▸ Artboards to Files as the batch alternative. Show the four files in the folder.
Lab: The Campaign (38 min), Module 5 deliverable

Learners follow Steps 1–4 using labs/module-5/practice/l15-campaign-copy.txt (sizes, copy, recomposition notes), the linked logo.png from L14, l15-key-art.png or their Module 4 composite, l15-background-light.jpg, and their L13 styles. Optional shared grade: the same adjustment layer at the top of each artboard, or the Module 4 LUT loaded into a Color Lookup layer on each (adjustment layers can't be linked, so each copy is updated by hand). Save the master PSD with its linked files in the same project folder.

Definition of done (the lesson's checklist): one master PSD with poster, square, story and banner artboards; logo and key art placed as linked Smart Objects; type driven by the 5.1 Paragraph/Character Styles; each size recomposed for its aspect ratio, safe zones respected; all artboards exported in one pass via Export As; a single source edit updates the whole set.

Circulate for: the poster artboard built small and scaled up; the key art upscaled past 100% on the poster (the practice PNG is 2400 px wide, so keep it at or below 100%); a banner that's the poster squashed; logo placed embedded on some artboards; text in the story's top or bottom band. Model result on your screen: labs/module-5/instructor/l15-campaign-reference-INSTRUCTOR.png.

Showcase: one edit, every artboard (4 min)

Two or three volunteers (or you) run the lesson's proof live: open the linked logo (or key art), make a visible change, save. Back in the master, every artboard updates (if one doesn't: Layer ▸ Smart Objects ▸ Update All Modified Content). Re-export with Export As. The room names what stayed identical across sizes and what was recomposed.

Mistakes to pre-empt
  • Small master, scaled up. Scaling up for print softens everything. Biggest first, always.
  • Squashing instead of recomposing. A 3:1 banner is not a shrunken poster. Anchor the focal point, rearrange the rest.
  • Expecting per-artboard color modes. All artboards share one mode and one ppi. RGB master; CMYK for print is a separate final step.
  • Trying to link an adjustment layer. It can't be linked. Duplicate it into each artboard or reload the same LUT; update each copy if the look changes.
  • Safe zones ignored. Story UI overlays cover the top and bottom; banners crop at the edges. Keep text clear.
  • Moving the project folder mid-build. Links break (see the module risk note).
Check for understanding: self-check + journal

Answers: Q1 A) the print poster, the largest; Q2 C) Place Linked it into each artboard; Q3 B) File ▸ Export ▸ Export As with all artboards; Q4 D) anchor the focal point and spread the elements horizontally; Q5 A) keep the master RGB and convert an exported copy to CMYK as a final step; Q6 C) Layer ▸ Smart Objects ▸ Update All Modified Content. Full explanations in the Answer Key.

Journal: Find a brand you admire and list every place its campaign appears (feed, story, print, web). What stays identical across them, and what is recomposed? That is the master-and-instances split in the wild.

Differentiation

Fast finishers (if time / homework): the lesson's solo variations: two more sizes (a billboard and an email header, sized to the destination's spec) without recreating any shared element; a light and a dark variant of the whole set by swapping one linked background (l15-background-light.jpg → l15-background-dark.jpg with Relink to File; a Color Overlay layer style on the linked logo keeps it readable on dark); Package the project and have a "client" change the linked logo on their machine. Going further: pair it with data-driven graphics (Module 6) for localized versions.

Struggling learners: two artboards first (poster and square), both fed by the same linked logo and key art, exported with Export As. Add the story and banner once that works. The must-have is the one-edit proof: change the source, see both update.

Closing the Session

Module 5 wrap-up (5 min, 2:55–3:00)

Recap the arc: a named type voice (5.1) → self-updating templates (5.2) → a full campaign from a single master (5.3). Exit ticket (on a sticky note): "One thing I decided once today and will never set by hand again is ___." Homework from the lessons' "Before the Next…" lists: ship one campaign set (4+ sizes) from a single master file; prove a one-edit update propagates across every artboard; finish any solo variation started in class; write the three journal entries. Remind learners to keep northwind-campaign/ intact (and to use File ▸ Package if they move it to another machine). Preview Session 6 (Module 6, Generative + Automation, Advanced): "You have systems for consistency; next you get systems for speed and volume: generative compositing, conditional Actions, and data-driven graphics that produce dozens of variations from one template."
