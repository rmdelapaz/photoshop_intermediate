Growth mindset: taste is a set of decisions

"Good taste" in type and layout isn't magic; it's decisions made once and applied consistently. A scale, a pair of typefaces, a grid: each is a rule you can name. Templates feel like extra work the first time and pure magic every time after. Expect the first build to feel slow. That's the setup cost of a system, and it pays you back on every job.

L13

Type Systems, Styles & Grids (Lesson 5.1)

55 min
By the end you can
  • Build a modular type scale and a clear hierarchy from it
  • Create and apply Paragraph and Character Styles
  • Turn on real OpenType: ligatures, true small caps, oldstyle figures
  • Set up columns and a baseline grid (the document grid, spaced at your leading)
  • Pair typefaces from Adobe Fonts with intent
Key ideas
  • Modular scale: one base size × one ratio (1.25, 1.333, 1.618). Assign roles to steps and never freehand a size again.
  • Four cheap levers of hierarchy: size, weight, color and space. Often weight or space says "this matters" better than size.
  • Styles bottle a spec (font, size, leading, tracking, color, OpenType) under a name. Edit the style once and every instance updates.
  • No faux styling. Faux Bold and Faux Italic smear a regular weight. Use a real Bold/Italic or choose another face.
  • Photoshop has no true baseline grid. Set the document grid to your body leading, give text that leading (or a multiple), and align each block's first baseline by eye.
  • Usually two typefaces: one display, one text, chosen to contrast.

Worked example: a type system (the guided build)
  1. Set the scale. Units & Rulers ▸ Type ▸ Pixels (or keep points and use the same numbers as pt). Base 16, ratio 1.25 → 13 / 16 / 20 / 25 / 31 / 39. Caption 13, Body 16, Subhead 20, H2 25, H1 31, Display 39.
  2. Build the grid. New Guide Layout: 3 or 6 columns, a gutter, margins. Then Preferences ▸ Guides, Grid & Slices: Gridline Every 24 px (for 16 px body), Subdivisions 1. Show it with Ctrl/⌘+'.
  3. Create styles. Set one line per role correctly (font, size from the scale, leading = grid increment or a multiple, tracking, color, OpenType on). With it selected, create a new Paragraph Style and name it. Repeat per role; add Character Styles for links/emphasis.
  4. Prove the system. Lay out the page with named styles only. Nudge each block so its first baseline sits on a gridline (zoom in, arrow keys). Edit the Body style by one step and watch the page re-flow. Save the PSD: its styles feed Lesson 5.3.

Text won't snap to the grid? It never will: View ▸ Snap To ▸ Grid snaps a layer's edges, not its baselines. Keep leading equal to the grid increment and align each block's first baseline by eye. L14

Smart-Object Templates & Linked Assets (Lesson 5.2)

55 min
By the end you can
  • Explain what a Smart Object protects and why it is non-destructive
  • Choose between embedded and linked Smart Objects
  • Build a mockup template with a warped placeholder
  • Use Replace Contents and Place Linked to swap art in one move
  • Update one linked file and have every design using it refresh
Key ideas
  • A container you can refill. Transforms, warps, Smart Filters and layer styles live on the Smart Object; Replace Contents swaps what's inside and keeps all of them.
  • The catch: the container's transform is applied to whatever you swap in. Build placeholders at the exact pixel size (or at least the exact aspect ratio) of the art they'll hold.
  • Embedded = stored inside the PSD, each copy independent (one-off protection). Linked (File ▸ Place Linked) = points at a file on disk that many documents share (the backbone of a system).
  • Effects on the container, not the art. Warp the placeholder; put shadows on a Multiply layer and highlights on a Screen layer above it, clipped.
  • Link discipline. Don't move or rename linked files; File ▸ Package gathers them for handoff.
Worked example: a reusable mockup (the guided build)
  1. Place the placeholder. Open l14-mockup-poster-wall.jpg (or your own surface photo). Rectangle tool (U), click once and enter the art's exact size: 1200 × 1800 px for the practice designs. Right-click ▸ Convert to Smart Object. Free Transform (Ctrl/⌘+T) ▸ Warp (or Perspective Warp) to fit the surface.
  2. Light it into the scene. A layer set to Multiply above the placeholder: paint the surface's shadows and creases back over the art. A Screen layer for highlights. Clip both to the placeholder (Alt/⌥-click the line between the layers).
  3. Swap in real art. Double-click the placeholder (it opens in its own tab), place your design, save, close. Prefer Place Linked for art that several mockups share.
  4. Prove reuse. Layer ▸ Smart Objects ▸ Replace Contents with another design at the same pixel size. The perspective, shadows and highlights hold. Save as your template.

L15

Campaign from One Master (Lesson 5.3)

60 min
By the end you can
  • Use artboards to hold multiple sizes in one document
  • Share art across artboards with linked Smart Objects
  • Adapt one design to portrait, square and landscape without redrawing it
  • Export every artboard at once with Export As
  • Deliver a coherent, on-brand campaign set from one file
Key ideas
  • Master and instances. The master owns the shared truth (key art, logo, tagline, grade); each artboard is a view onto it at one size and crop. Only layout and framing differ.
  • Design at the biggest size, export down. Usually the print poster. Scaling a small master up softens everything.
  • One color mode, one resolution for every artboard in a document. Keep the master RGB; CMYK for print is a separate final step on an exported copy.
  • Recompose, don't squash. Anchor the focal point first; stack for the story, center for the square, spread for the banner. Respect safe zones.
  • Adjustment layers can't be linked. For a shared grade, duplicate the layer (or reload the same LUT) into each artboard and update each copy.

Worked example: the campaign (the guided build)
  1. Set up artboards. New document (RGB), Artboards on. Add poster, IG square (1080²), story (1080 × 1920) and banner (1500 × 500), using presets where they exist and custom sizes otherwise. Design the poster first.
  2. Share the essentials. File ▸ Place Linked the logo and key art into each artboard. Copy a styled text layer in from your L13 file so its Paragraph Styles come along; apply them to each headline and subhead.
  3. Recompose per size. Anchor the focal point, rearrange around the aspect ratio, respect safe zones. Optional shared grade: the same adjustment layer or the same LUT in a Color Lookup layer at the top of each artboard.
  4. Export the set. File ▸ Export ▸ Export As, all artboards, format and scale, Export (or File ▸ Export ▸ Artboards to Files). Then open the linked logo or key art, change it visibly, save; every artboard updates (else Layer ▸ Smart Objects ▸ Update All Modified Content). Re-export. Save the master with its linked files in the same folder.

Module 5 Summary

  • A type system (scale + styles + grid) gives every layout one consistent voice.
  • Smart Objects protect art and, via linked files, let one source update many designs.
  • Artboards hold every size in one master; Export As ships them together.
  • Design the largest first, share the essentials, recompose per aspect ratio.
