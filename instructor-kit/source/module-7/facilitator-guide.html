Module 7: Multi-Shot Techniques

How to teach the two lessons of the Going Further tier (panoramas, HDR and focus stacking, then Timeline animation and export) and how to run the capstone kickoff that closes Session 7. The theme of the day is "many frames, one result": three merges that beat the limits of a single frame, then layers turned into motion, then a brief that turns "make something cool" into a project learners can finish.

2 lessons + capstone kickoff Session 7 · 3 hrs incl. break Lessons L19–L20 (+ L21 kickoff) Level Intermediate Tier Going Further

How to Use This Guide

  • Same rhythm as every module: Frame → Demo → Guided build → Solo variation → Check. Demo one step, let the room do it on the practice files, then move on. Each lesson plan gives a timing table, a demo script with Say: lines, the lab, the mistakes to pre-empt, a check for understanding, and differentiation notes.
  • Name every menu path out loud and give both shortcut forms: Ctrl on Windows is ⌘ on Mac, Alt is ⌥.
  • Teal = hands-on, amber = watch-outs. In L19 the watch-outs are about source frames (overlap, a moved subject, a skipped focus distance); in L20 they are about which track a layer has and GIF weight.
  • The last 42 minutes run Lesson 8.1 (L21, The Brief & the Plan) as the capstone kickoff. Its full lesson plan (objectives, demo script, mistakes, self-check answers) lives in the Module 8 facilitator guide (source/module-8/facilitator-guide.html); this guide gives only the kickoff segment and how it hands off to Session 8.
  • Quiz answers below match the workbook's Self-checks; the Answer Key explains each one.
The #1 risk of Module 7: the merges eat the clock

Photomerge, Merge to HDR Pro and Auto-Blend Layers are processor-heavy, and a learner who feeds them a folder of 45-megapixel raw files can lose ten minutes to one progress bar. In class, everyone merges the practice sets (1800 × 1200 px JPEGs, a few seconds each on a normal laptop); their own full-resolution sets are the take-home "Now You." The second risk is the session's shape: two lessons plus the kickoff leave no slack, so run the demos crisply and protect the kickoff. Session 8 is built on learners arriving with a written brief and a plan.

Merge to HDR Pro and the practice bracket

HDR Pro reads each frame's exposure from its metadata. The three practice frames carry generated exposure data (f/8, ISO 100, 1/250 s, 1/60 s, 1/15 s, a 2-stop bracket), so the merge normally runs without questions. If a learner's copy has lost its metadata (some cloud-sync tools and messaging apps strip it), Photoshop opens a Manually Set EV dialog. The answer is in labs/module-7/README.md: choose the shutter-speed option and enter f/8, ISO 100 and the three shutter speeds, darkest frame fastest. Rehearse this once on your own machine so you can talk a learner through it in thirty seconds.

Lesson Plans

L19

Panoramas, HDR & Focus Stacking (Lesson 7.1)

55 min
Objectives
  • Shoot overlapping frames and stitch a panorama with Photomerge
  • Bracket exposures and combine them with Merge to HDR Pro for wider range
  • Shoot a focus series and focus-stack it with Auto-Align + Auto-Blend
  • See the shared engine (auto-align, then blend) behind all three
  • Clean the seams, ghosts, and edges these merges leave behind
Timing
3mThe goal: beat a single frame (lesson slider)
5mMental model: align, then blend · three jobs, one engine
4mThe three front doors: Photomerge, HDR Pro, Load Files into Stack + Auto-Blend
10mGuided build Step 1: panorama
12mGuided build Step 2: HDR
10mGuided build Step 3: focus stack
5mStep 4: clean the joins (the unifying grade can finish at home)
6mSelf-check, recipe card, journal (Now You goes home)
Teaching sequence & live-demo script
  1. The goal (3m). Show the L19 slider: one frame catches a slice, three stitched frames hold the whole vista. Say: "A single frame has three limits: it is only so wide, it only holds so much range from shadow to highlight, and only so much of it is in focus. Today we beat all three with the same trick: shoot several frames and let Photoshop combine them."
  2. Align, then blend (5m). Draw the pipeline on the board: source frames → Auto-Align → Blend → one image. Say: "Auto-Align finds common detail and warps the frames into registration. Blend then picks, pixel by pixel, the best contribution: the overlap for a pano, the well-exposed tone for HDR, the sharpest region for a stack." Then the three-column table: vary angle → wider field; vary exposure → wider range; vary focus → deeper focus. Say: "Change only the one variable the technique needs. Hold everything else still. That is why a tripod and a 2-second timer pay off, especially for HDR and stacking, where frames must register to the pixel."
  3. Three front doors (4m). Point at each menu without running it yet: File ▸ Automate ▸ Photomerge; File ▸ Automate ▸ Merge to HDR Pro; File ▸ Scripts ▸ Load Files into Stack followed by Edit ▸ Auto-Align Layers and Edit ▸ Auto-Blend Layers…. Then the warning from the lesson: Say: "Garbage frames in, garbage merge out. Too little overlap and the pano won't stitch; something moves mid-bracket and HDR shows ghosts; skip a focus distance and the stack has a soft band."
  4. Step 1: panorama (10m). File ▸ Automate ▸ Photomerge → Browse → select the four files in l19-pano/. Layout Auto; tick Blend Images Together and Content Aware Fill Transparent Areas; OK. While it runs: Say: "These frames overlap by about 35%. The dialog doesn't measure overlap for you; aim for roughly 30% when you shoot." Show the result's layer masks (one per frame): the stitch is just masks, the Module 1 idea again. Crop or accept the filled edges, then zoom to 100% on a seam and heal anything that doubled. Save as pano-working.psd (suggested name). Say: "The frames were deliberately shot with slightly different brightness and some vignetting. Blend Images Together is what hides that."
  5. Step 2: HDR (12m). File ▸ Automate ▸ Merge to HDR Pro → Browse → the three files in l19-hdr/; leave Attempt to Automatically Align Source Images on; OK. In the merge dialog, tick Remove Ghosts. Say: "A bird flew across the window between shots. Toggle Remove Ghosts and watch the three faint birds become one." Set Mode: 16 Bit and choose Local Adaptation; nudge the sliders toward believable: window detail back, room detail visible, no halos around the window frame. Say: "Keep it believable. Want every stop kept for later? Set 32 Bit instead and tone-map afterwards with Camera Raw." OK; save as hdr-working.psd. If a learner gets the Manually Set EV dialog, walk them through the README values.
  6. Step 3: focus stack (10m). File ▸ Scripts ▸ Load Files into Stack → Browse → the four files in l19-stack/; tick Attempt to Automatically Align Source Images; OK. Say: "The frames breathe: the image grows a hair as focus moves, which is what the auto-align fixes." Select all four layers, Edit ▸ Auto-Blend Layers… → Stack Images, tick Seamless Tones and Colors → OK. Show the masks Photoshop painted: white where each frame was sharpest. Zoom to 100% on the ruler and the wall chart's fine print. Say: "If a patch is soft, paint the mask of the frame that had it sharp. Auto-Blend can only choose from the sharp regions you captured." Save as stack-working.psd.
  7. Step 4: clean the joins (5m). On each result, 100% zoom: heal a stitch artifact, a ghost remnant, or a soft band on a separate layer. Then the lesson's finish: a Module 4 unifying grade so all three feel like your work. Say: "One careful shoot beats any repair, but every merge still gets a 100% inspection." If time is short, the grade moves to homework; the inspection does not.
Lab: Merge Three Ways, then Now You

Guided build on the three practice sets in labs/module-7/practice/: l19-pano/ (4 overlapping frames), l19-hdr/ (−2 / 0 / +2 bracket), l19-stack/ (4 frames, near to far). Learners with their own small sets may use them for any one step. Solo variation (at home): a vertical panorama; a subtle HDR and a deliberately overcooked one; a focus stack of a small object compared with a single f/8 frame. Going further: a bracketed panorama (HDR each position, then stitch). Details in labs/module-7/README.md.

Circulate for: Photomerge ticks set before OK (Blend Images Together, Content Aware Fill Transparent Areas); Remove Ghosts on for the bracket; Mode deliberately chosen (16 Bit to tone-map now, 32 Bit to keep range); all four stack layers selected before Auto-Blend, with Stack Images (not Panorama); learners actually zooming to 100%.

Definition of done: the lesson's five-item checklist: a stitched panorama with invisible seams; an HDR merge with recovered highlights and shadows and no ghosts; a focus stack sharp front to back; edges cropped or filled and joins healed at 100%; a consistent grade across all three.

Mistakes to pre-empt
  • Transparent, ragged edges on the panorama. Content Aware Fill Transparent Areas was unticked. Crop them off, or rerun with the tick. Either is fine; checking the filled edges at 100% is not optional.
  • The pano bows or bends. Wide pans on a flat projection curve straight lines. Try Cylindrical or Spherical in Photomerge's Layout list; for their own shoots, keep the horizon centered; Filter ▸ Adaptive Wide Angle straightens afterwards.
  • Three ghost birds in the window. Remove Ghosts was off. Re-open the merge and tick it; for their own brackets, the lesson's fix is prevention (shoot when nothing moves).
  • HDR result looks radioactive. Every slider pushed to the right. Ask: "Would a viewer believe this room?" Pull Detail and Vibrance back; the overcooked version is a Now You exercise, not the deliverable.
  • Auto-Blend grayed out or odd. Only one layer selected, or the layers are still the locked Background. Select all four (click the top one, Shift-click the bottom) and run it again.
  • "Panorama" chosen in Auto-Blend. That is the other Blend Method. Stack Images is the focus-stacking option.
  • A soft band across the table. On the practice set this only happens if a frame was left out (try it deliberately: drop frame 2 and watch the band appear). On real shoots: reshoot with smaller focus steps, or mask in a sharper frame by hand.
  • Feeding full-resolution raw sets in class. Long progress bars stall the room. Practice files now, own sets at home.
Check for understanding: self-check + journal

Answers: Q1 B) Photoshop auto-aligns the frames, then blends the best of each; Q2 C) The focus distance; Q3 D) Content Aware Fill Transparent Areas; Q4 A) Tick Remove Ghosts in Merge to HDR Pro; Q5 B) 32 Bit, then tone-map later in Camera Raw; Q6 D) A focus distance was skipped, so reshoot with smaller steps or mask in a sharper frame. Full set in the Answer Key.

Journal (3 min, finish at home if needed): Which single-frame limit frustrates you most: width, range, or depth? Plan the shoot that would beat it with a multi-shot merge.

Differentiation

Fast finishers: rerun Photomerge with Cylindrical and Reposition layouts and compare the horizon; rerun HDR at 32 Bit and tone-map in Camera Raw; drop frame 2 from the stack to see the soft band the lesson's FAQ describes. Or start the Going Further: HDR-then-stitch on their own bracketed pan.

Struggling learners: one merge done well beats three done badly. Prioritize Photomerge (the most forgiving), then the focus stack; let them watch the HDR demo and do it at home. Give them the recipe card, and the mantra: align first, blend second.

L20

Timeline Animation & Export (Lesson 7.2)

50 min
Objectives
  • Choose between Frame Animation and the Video Timeline
  • Build a frame loop with tweening
  • Animate layer position, opacity, and style with keyframes (and scale, via Smart Objects)
  • Loop cleanly and shape timing so motion feels natural
  • Export a GIF (Save for Web) or an MP4 (Render Video)
Timing
3mThe goal: make it move (lesson slider)
5mMental model: frames vs keyframes (flip-book vs smooth path)
4mThe Timeline panel tour + the two export doors
6mGuided build Step 1: start the timeline
14mStep 2: keyframe the moves
8mStep 3: loop and shape the timing
6mStep 4: export both (the MP4 render may finish at home)
4mSelf-check, recipe card, journal (Now You goes home)
Teaching sequence & live-demo script
  1. The goal (3m). Show the L20 slider and, if you like, the reference loop in labs/module-7/instructor/l20-reference-loop.gif. Say: "Photoshop is an animator hiding in plain sight. Everything that moves in this loop is a layer you already know how to make."
  2. Frames vs keyframes (5m). Two columns on the board. Frame Animation = the flip-book: discrete frames, each a layer arrangement, each with its own hold time, Tween to fill in-betweens. Video Timeline = the smooth path: each layer gets a track, you set keyframes and Photoshop interpolates. Say: "Short, loopy GIF with exact frames: Frame Animation. Smooth glides and fades, or you plan to export video: the Video Timeline. You can convert between them, but picking the right one first saves rework."
  3. Panel tour + export doors (4m). Window ▸ Timeline. Point at the single button (Create Video Timeline) and its dropdown arrow (Create Frame Animation). Twirl a layer open: normal layers show Position, Opacity, Style; a Smart Object shows Transform instead of Position. Say: "No scale track on a normal layer, at all. If it's going to grow or rotate, make it a Smart Object first. And there is no ease curve: keyframes are linear, or Hold for a jump." Then the two doors out: File ▸ Export ▸ Save for Web (Legacy) (Ctrl+Alt+Shift+S / ⌘+⌥+Shift+S) for GIF; File ▸ Export ▸ Render Video for MP4.
  4. Step 1 (6m). File ▸ Scripts ▸ Load Files into Stack → the three files in l20-anim/ (the L19 command, reused). Put the background at the bottom, badge and headline above; save as loop-working.psd (suggested name). Right-click the badge layer ▸ Convert to Smart Object. Say: "The badge will scale, so it becomes a Smart Object now, not after I find the missing track." Then Create Video Timeline; panel menu ▸ Set Timeline Frame Rate ▸ 24 fps; drag the right end of each layer's bar to the 3-second mark, then drag the work-area end handle above the ruler to match.
  5. Step 2 (14m). Twirl open the badge. Playhead at frame 0; press Ctrl/⌘ + T and scale the badge small, commit, then click the Transform stopwatch. Move the playhead to about 0.6 seconds, scale it back to full size in its spot; Say: "Watch the diamond appear. After the stopwatch is on, any change at a new time drops a keyframe for you." Headline: at about 0.4 seconds click the Opacity stopwatch with Opacity 0% and the Position stopwatch with the headline nudged about 40 px down; at the 1-second mark set 100% and move it up into place. Scrub to show both moves.
  6. Step 3 (8m). Say: "A loop is seamless when the last frame matches the first." Hold the finished pose until about the 2-second mark, then add keyframes that return each layer to its frame-0 state by the last frame (small badge, headline invisible and low). Then the fake ease: add one extra keyframe just before the end of each move with only a small change left. Say: "Photoshop moves at constant speed. Put most of the move early and a little at the end, and the finish slows down." Press the play button (or Space) and adjust until it feels natural, not robotic.
  7. Step 4 (6m). File ▸ Export ▸ Save for Web (Legacy) → GIF, a modest color count, a little dither, Looping Options: Forever; show the file size readout in the preview's corner. Say: "Watch the size. If it balloons past a couple of megabytes, shrink the Image Size in this same dialog, or deliver an MP4." Save as loop.gif. Then File ▸ Export ▸ Render Video → H.264, a high-quality preset, the frame rate → Render → loop.mp4. Say: "The lesson says 1080p, which is the 16:9 case. Our practice design is square, so keep the Size at Document Size and the loop stays 1080 × 1080. One animation, two delivery formats."
Lab: A Looping Animation, then Now You

Guided build on the three pieces in l20-anim/ (or a learner's own simple layered design: a logo, a badge, a headline). Solo variation (start in class if time allows, finish at home): a cinemagraph from the six frames in l20-steam/: steam loops while the cup stays still, masked so only the steam animates; a pulsing layer-style glow; or the same 3-second loop rebuilt once in Frame Animation and once on the Video Timeline. Details in labs/module-7/README.md.

Circulate for: the badge converted to a Smart Object before keyframing; stopwatches clicked on the right property (Transform on the badge, Opacity and Position on the headline); the work area trimmed to 3 s so the GIF doesn't carry dead seconds; the last frame matching the first.

Definition of done: the lesson's checklist: a video timeline with keyframed Transform (or Position) and Opacity; transformed layers converted to Smart Objects (stay sharp); a seamless loop with natural-feeling timing; a GIF looping Forever and an MP4 exported; the GIF short and reasonably small. With L19, this completes the Module 7 deliverable.

Mistakes to pre-empt
  • "There's no scale property." The layer is a normal layer, which only has Position, Opacity and Style. Convert to Smart Object; the Transform track appears.
  • Scaled a normal layer anyway, now it's soft. Pixels were resampled. Undo, convert to a Smart Object, redo: it re-renders crisply at every frame.
  • Changed a value but no keyframe appeared. The stopwatch was never clicked, so the change applied to the whole clip. Click the stopwatch first, then change values at new times.
  • The loop jumps at the wrap-around. The last frame doesn't match frame 0, or the work area runs past the last keyframes. Copy the frame-0 values to the end and trim the work-area handle.
  • Robotic, constant-speed motion. Expected: Photoshop keyframes are linear. Add the extra near-the-end keyframe to fake the ease.
  • A 15 MB GIF. Too many pixels, colors, or seconds. Shrink Image Size in Save for Web, lower the color count, shorten the loop, or ship the MP4.
  • Banded gradients in the GIF. GIF is limited to 256 colors. More colors and a little dither help; for gradient-heavy work, the MP4 is the better deliverable.
  • Hunting for Save for Web in Export As. It is File ▸ Export ▸ Save for Web (Legacy), a separate command.
Check for understanding: self-check + journal

Answers: Q1 B) The Video Timeline; Q2 C) Convert the badge to a Smart Object so it gets a Transform track; Q3 A) Returning each layer to its frame-0 state by the last frame; Q4 D) Add an extra keyframe near the end of each move with only a small change left; Q5 B) File ▸ Export ▸ Save for Web (Legacy), GIF, Looping Options: Forever; Q6 C) An MP4 made with Render Video (H.264). Full set in the Answer Key.

Journal (3 min, finish at home if needed): What is one still design of yours that a few seconds of motion would improve, and which single element should move? Restraint matters in animation too.

Differentiation

Fast finishers: the cinemagraph from l20-steam/: Load Files into Stack, Create Frame Animation, panel menu ▸ Make Frames From Layers, set each frame's delay, and mask the top frames so only the steam area changes. Or animate a Style track (an Outer Glow pulsing on the badge). Going further (from the lesson): assemble a data-driven sequence from Module 6 on the Timeline.

Struggling learners: animate one property on one layer (headline Opacity 0 → 100 → 0) until the stopwatch-then-move rhythm clicks, then add the badge scale. Export only the GIF in class; the MP4 is one menu command at home.

Closing the Session

Module 7 wrap-up + capstone homework (10 min, 2:50–3:00)

Recap the arc: many frames into one still (align first, blend second) → layers into motion (keyframe the start and end, let Photoshop travel the middle) → everything you know into a brief and a plan. Exit ticket (on a sticky note): "Panorama, HDR, focus stack: which variable changes in each?" (Angle, exposure, focus distance.)

Homework, in two parts. 1. Finish the plan (first evening): complete the one-page brief and have someone else read the success criteria; finish the annotated moodboard (6–12 references); finalize the staged plan with milestones; gather source assets and confirm the license on anything they didn't shoot; write the L21 journal entry (the one-sentence objective). 2. Build it (before Session 8): work through Lesson 8.2, Studio Session: Build It, in passes (block-in, refine, polish) with named groups and versioned saves. Say it plainly: "Session 8 opens with a plan review in pairs and then a studio block for finishing, so arrive with the piece well underway, and with your brief, moodboard, and plan in hand."

Also from the lessons' "Before the Next Module": produce one multi-shot still of their own (pano, HDR, or stack) and one short animation exported as a GIF and an MP4, and write the L19 and L20 journal entries. Preview Session 8 (Module 8): "No new tools. You review plans in pairs, build in the studio, then present your capstone with a case study and give each other real critique."
