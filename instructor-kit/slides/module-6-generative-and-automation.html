L16

Generative for Compositing

Fill the gaps, not the vision.

The mental model

A fast, fallible assistant

  • Select → prompt short or empty → pick the best of 3 variations → mask + finish by hand
  • Superb at texture: sky, grass, pavement, walls; and at removals
  • Unreliable at specifics: hands, text, brands, exact counts
  • Every result on its own generative layer: never "generate and ship"
LIMIT It fills texture. It won't fix wrong perspective, light, or scale.
Where each tool lives

Expand · Fill · Harmonize

  • Room: Crop tool, Fill: Generative Expand, drag out, Generate
  • Remove: lasso with margin (and its shadow), empty prompt
  • Connect: small selection, gravel with small shadows
  • Harmonize: select the placed layer → task bar or Properties
  • Matches light, color, shadows to the background
  • Compare, keep the best, mask back what it changed
TIP Hide the pasted subject while you expand, so the model continues the scene.
Guided build: Harmonize a Composite

Five steps, then finish by hand

  • 1 Give it room (Generative Expand) · audit edges at 100%
  • 2 Remove the SALE sign, post, and shadow
  • 3 Grow connective tissue under the feet · mask it
  • 4 Harmonize the subject · mask back edges and face
  • 5 Grain + sharpen match · dodge & burn · one unifying grade

Limits, ethics & licensing

Audit, match, disclose

  • Zoom to 100%: artifacts, repeats, soft patches
  • Generated areas are often softer: match grain and sharpening
  • Firefly is designed to be commercially safe; partner models may have other terms
  • Journalism and documentary: generative changes may be off-limits
MANTRA The model gives you a head start, never the finish line.

Where scripting begins

Read it before you write it

// resize-folder.jsx — File ▸ Scripts ▸ Browse
for (var i = 0; i < files.length; i++) {
    var doc = app.open(files[i]);
    var scale = 2000 / Math.max(doc.width.value, doc.height.value);
    doc.resizeImage(doc.width * scale, doc.height * scale);
    // save web_ copy at quality 10, close
}
RUN on a copy of a folder · rulers in Pixels · loops, math, logic = script
Which tool when?

Action · Variables · Script

  • Action: same steps on every file (with a conditional for mixed input)
  • Variables: same layout, changing content
  • Script: loops, math, renaming, lookups, per-file decisions
MANTRA Design the difference as data, and the count stops mattering.
