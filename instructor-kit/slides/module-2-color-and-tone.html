L04

Color Management & Working Spaces

Invisible work that makes every grade trustworthy.

Mental model

Color in a container

  • Width = working space (gamut)
  • Fineness = bit depth: 256 vs 32,000+ steps
  • "R 220" means nothing without the container
MANTRA Capture wide, edit deep, convert down last.
Pick the container for the job

sRGB · Adobe RGB · ProPhoto

  • sRGB: web, social, email. Assume the internet is sRGB
  • Adobe RGB: print, the cyans and greens sRGB clips
  • ProPhoto: heavy RAW grading, masters. Always 16-bit
CONVERT, DON'T ASSIGN Convert remaps and keeps the look. Assign relabels and shifts it.
Guided build · 24 min

Set up & diagnose

  1. Edit ▸ Color Settings: Adobe RGB (1998) or sRGB · Preserve Embedded Profiles · mismatch warnings on
  2. Image ▸ Mode ▸ 16 Bits/Channel · Window ▸ Histogram · one-sentence diagnosis
  3. Duplicate the sky · one copy 8-bit · same hard Curves on both · zoom in
  4. Save master · Image ▸ Duplicate (merged) · Convert to Profile ▸ sRGB · 8-bit · export
HABIT Diagnose before you edit: read, name, then reach.
Checklist · Now You starts

Trustworthy color

  • Deliberate working space · working file is 16-bit
  • Histogram diagnosed in one sentence, before editing
  • Banding seen with your own eyes
  • Web copy Converted to sRGB, not assigned
NOW YOU Histograms a–e cold · then the lagoon two ways at home
L05

Grading with Curves, Gradient Maps & LUTs

A look, not just a fix.

Mental model

Every grade is a remap

  • Correcting: "what is wrong?" Grading: "what should it feel like?"
  • Per-channel Curves: the precision instrument
  • Gradient Map: tones in, ramp colors out
  • LUT: a saved recipe you pour onto any image
MANTRA Correct, then grade, then bottle.
Teal & gold in Curves

Contrast first, then color

  • Layer 1: gentle RGB S-curve
  • Layer 2: Blue shadow end up, highlight end down
  • Truer teal: Green up a touch or Red down in the shadows
Blend it, don't bake it

Gradient Map + LUT

  • Gradient Map teal → gold · Color or Soft Light · ~20–30%
  • Mask locally: skin natural, background moody
  • Color Lookup layer ▸ 3DLUT File ▸ Load 3D LUT…
WATCH At 100% Normal a Gradient Map is garish and kills detail.
Guided build · 30 min

Grade & bottle it

  1. 16-bit · neutral base (gray card) · Save As grade-working.psd
  2. S-curve → Blue split → Gradient Map at ~20–30%
  3. Mask the grade off skin or highlights
  4. Save · Shift-click masks off · hide non-grade layers · File ▸ Export ▸ Color Lookup Tables · masks back on
  5. Pier: Color Lookup ▸ Load 3D LUT… ▸ your .cube
WHY Export bakes every visible adjustment; a LUT can't store a mask.
Checklist · Now You starts

A look you can reuse

  • Contrast before color · per-channel Curves grade
  • Gradient Map blended · at least one mask
  • LUT exported and re-applied to a second image
  • grade-working.psd saved for L06
NOW YOU Warm summer · cold thriller · faded matte

L06

Match, Split-Tone & Soft-Proof

The Module 2 deliverable.

Split-tone by zone

Cool shadows, warm highlights

  • Color Balance: Shadows → cyan/blue · Highlights → red/yellow
  • Midtones near neutral: skin lives there
  • Judge on skin: warmly lit, not sunburnt
WATCH Color Balance opens on Midtones. Switch the Tone first.
Match & proof

Sample, then simulate

  • Color Sampler on comparable points · read Window ▸ Info
  • Curves: tones before colors · black, white, then mid
  • View ▸ Proof Setup ▸ Custom: printer profile · Relative Colorimetric or Perceptual · BPC · Simulate Paper Color
  • Proof Ctrl/⌘ Y · Gamut Warning Ctrl/⌘ ⇧ Y
DEMO Neon dies on paper: l06-neon-proof.jpg
Guided build · 34 min

Split-tone & proof

  1. grade-working.psd → Save As finish-working.psd · Color Balance split
  2. Companion: samplers · Curves until the values meet
  3. Soft-proof · Gamut Warning · masked Hue/Saturation until it clears
  4. Save master · merged duplicates: sRGB 8-bit JPG + printer profile PDF/TIFF
Deliverable · checklist

One look, two destinations

  • Believable split-tone · companion matched
  • Proofed with intent + paper simulation · warnings resolved
  • Web (sRGB) file + print (printer-profile) file
  • Layered master still wide + 16-bit
DELIVERABLE Web JPG + print PDF/TIFF
