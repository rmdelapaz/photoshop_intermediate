L19

Panoramas, HDR & Focus Stacking

Lesson 7.1 · shoot many, blend to one.

The goal

Three limits of a single frame

  • Only so wide → panorama
  • Only so much range → HDR
  • Only so much in focus → focus stack
IDEA Shoot several frames; let Photoshop combine them.
Mental model

Align, then blend

  • Pano: vary angle
  • HDR: vary exposure
  • Stack: vary focus
  • Hold everything else still
Three front doors

Same engine, three menus

  • File ▸ Automate ▸ Photomerge
  • File ▸ Automate ▸ Merge to HDR Pro
  • File ▸ Scripts ▸ Load Files into Stack → Auto-Align → Auto-Blend Layers…
WATCH Garbage frames in, garbage merge out.
Steps 1–2 · 10 + 12 min

Panorama, then HDR

  1. Photomerge ▸ l19-pano/ · Layout Auto
  2. Tick Blend Images Together + Content Aware Fill Transparent Areas
  3. Merge to HDR Pro ▸ l19-hdr/ · tick Remove Ghosts
  4. 16 Bit + Local Adaptation = finished now · 32 Bit = keep range, Camera Raw later
TIP Asked to "Manually Set EV"? f/8 · ISO 100 · 1/250, 1/60, 1/15 s.
Steps 3–4 · 10 + 5 min

Focus stack, then clean the joins

  1. Load Files into Stack ▸ l19-stack/ · tick Attempt to Automatically Align
  2. Select all layers ▸ Edit ▸ Auto-Blend Layers… ▸ Stack Images + Seamless Tones and Colors
  3. Ctrl/⌘ 1 (100%) on every seam, ghost, soft band · heal on a layer
  4. One Module 4 unifying grade across all three
Lab · merge three ways

Done when…

  • A panorama with invisible seams
  • An HDR merge: highlights + shadows recovered, no ghosts
  • A focus stack sharp front to back
  • Edges cropped or filled · joins healed at 100%
  • A consistent grade across all three
MANTRA Align first, blend second.
Break · 13 minutes

Stretch, refill, rest your eyes

Ahead: open l20-anim/ and read L20's "Frames vs Keyframes."

L20

Timeline Animation & Export

Lesson 7.2 · make it move.

Mental model

Flip-book or smooth path?

  • Frame Animation: discrete frames, exact timing, Tween fills in-betweens
  • Video Timeline: keyframes, Photoshop interpolates
  • Short loopy GIF → frames · glides, fades, video → timeline
RULE Picking the right one first saves rework.
Window ▸ Timeline

What each layer can animate

  • Normal layer: Position · Opacity · Style
  • Smart Object: Transform (scale + rotation) instead of Position
  • Keyframes: linear (or Hold) · no ease curve
WATCH Will it grow or rotate? Smart Object first.
Steps 1–2 · 6 + 14 min

Start the timeline, keyframe the moves

  1. Load Files into Stack ▸ l20-anim/ · badge ▸ Convert to Smart Object
  2. Create Video Timeline · panel menu ▸ Set Timeline Frame Rate ▸ 24 fps · trim to 3 s
  3. Badge: Transform stopwatch at frame 0 (small) → later, full size
  4. Headline: Opacity 0 → 100 + a small upward Position move
Steps 3–4 · 8 + 6 min

Loop it, ease it, ship it twice

  1. Hold the pose, then return every layer to its frame-0 state by the last frame
  2. Fake ease: extra keyframe near the end, small change left
  3. Save for Web (Legacy) ⇧ Ctrl+Alt S / ⇧ ⌘⌥ S → GIF · Looping Forever
  4. File ▸ Export ▸ Render Video → H.264 · square file: Size = Document Size
WATCH GIF past a couple of MB? Shrink it, shorten it, or ship the MP4.
Lab · a looping animation

Done when…

  • Keyframed Transform (or Position) and Opacity
  • Scaled layers are Smart Objects: still sharp
  • Seamless loop, natural timing
  • loop.gif (Forever, small) + loop.mp4
DELIVERABLE Three clean merges + one loop, as GIF and MP4.
8.1

Capstone Kickoff: The Brief & the Plan

The capstone begins on paper, not in Photoshop.

The brief is the contract

Six parts, one page

  • Objective · Audience · Deliverables + specs
  • Constraints · Success criteria · References
  • Pin every adjective to a spec or a reference
MANTRA If you can't check it, it isn't in the brief.
Work block · 32 min

Brief, moodboard, plan

  1. 14m Write the brief; success criteria as a checkable list
  2. 10m Start the moodboard: first 3–4 references, one note each
  3. 8m Plan: stages → module skills, assets, 2–3 milestones
SCOPE Ambitious but finishable · stretch goals must be cuttable.
Before Session 8

Finish the plan, then build

  • Brief done · someone else reads your success criteria
  • Moodboard: 6–12 annotated references · assets gathered, licenses checked
  • Build it (Lesson 8.2): passes, named groups, versioned saves
  • Bring brief, moodboard, plan, and the working file

Session 8: plan review in pairs, studio, then present.
