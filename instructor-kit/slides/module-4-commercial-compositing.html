L10

Match Perspective, Scale & Lens

A composite dies on geometry first.

Mental model

Everyone shares a horizon

  • Horizon = the camera's eye level, visible or not
  • Receding parallel edges meet at a vanishing point on it
  • Every added element must share that one line
PLAZA horizon y = 700 · vanishing point (1260, 700)
Scale by the ground, not the eye

Feet first, then the horizon

  1. Set the element's ground-contact point
  2. CtrlT / ⌘T, scale from the feet
  3. Stop when the horizon crosses it at the same body height as the people already there
WATCH proportional by default now: Shift switches it OFF
Planes and lenses

Perspective Warp: Layout, then Warp

  • Convert to Smart Object first, so the warp stays editable
  • Layout: a quad on each plane · Warp: drag pins to the vanishing lines
  • People: a touch of Free Transform ▸ Distort is enough
  • Wide lens exaggerates depth; long lens flattens it
WATCH warp fixes geometry, not optics · grayed out? Use Graphics Processor
Guided build

Place one element

  1. Line tool along two receding edges → vanishing point → horizontal guide (Ctrl/⌘R rulers)
  2. Place; set the feet; scale to the horizon
  3. Perspective Warp strong planes toward the vanishing point
  4. Step back: flatter or rounder than the scene? Save the layered PSD
DONE WHEN one horizon · feet on the ground · right size for the distance · planes agree
L11

Light, Shadows & Reflections

Nothing real floats.

Read the light first

Direction · Hardness · Color

  1. Where? Existing shadows point away from the source
  2. How hard? Crisp edges = direct sun · soft = overcast
  3. What color? Warm sun, cool shade, green bounce
RELIGHT clipped 50% gray Soft Light D&B + clipped Color Balance / Photo Filter
The two-shadow habit

Touching, and where the light is

Subject + clipped light/color
Contact shadow · Multiply
Cast shadow · Multiply
Background 🔒
  • Contact: tiny, dark, barely blurred
  • Cast: skewed away from the light
  • Crisp near, soft and pale far
WATCH shadows are colored, not black: cool/blue outdoors
Build the cast shadow

Silhouette → fill → skew → blur → fade

  1. Ctrl/⌘-click the mask thumbnail (or layer thumbnail)
  2. New layer below · Edit ▸ Fill very dark · deselect · Multiply
  3. Free Transform ▸ Distort/Skew onto the ground
  4. Blur Gallery ▸ Tilt-Shift or Field Blur: sharp near, soft far
  5. Gradient mask to fade; tint to the scene's shadows
If the floor is glossy

Reflections

  • Duplicate → Edit ▸ Transform ▸ Flip Vertical
  • Align the bases perfectly
  • Opacity ~25–40% · blur that increases downward · mask a fade
DONE WHEN relit to match · contact + cast shadow · tinted · reflection if glossy · PSD saved

L12

Atmosphere & the Unifying Grade

The final handshake.

Mental model

Distance has a look

  • More air = less contrast, less saturation, shifted toward the sky color
  • Far elements as crisp as the foreground feel pasted forward
  • Lower contrast + a little haze on far elements = depth
Atmosphere between, grade on top

The finished stack

★ Unifying Grade (LUT / Curves)
Subject + clipped light/color
Contact + cast shadows
Atmosphere · far elements only
Background 🔒
  • Unify last, grade once
  • Neutral and correct first
  • One dial beats twenty
WATCH haze above the grade escapes it and looks pasted on
Guided build

Depth, then one grade

  1. Clipped Curves on far elements: less contrast, lifted blacks
  2. Haze layer (Normal), sky color, very low flow
  3. Color Lookup or Curves + Color Balance group on top
  4. Vignette + glow + grain · flatten a copy · sRGB · export
DONE WHEN far recedes · one grade over all · key visual exported 🏆
