L07

Skin & Frequency Separation

Even tone, real texture.

Mental model

Two frequencies

  • A blur kills both → plastic
  • Split them → fix each on its own
  • Tone on Low, texture on High
Apply Image depends on bit depth

Build the separation

  1. Duplicate twice → Low (bottom), High (top) · hide High
  2. Low: Gaussian Blur until pores vanish, features stay (often 4–8 px) · note it
  3. High: Image ▸ Apply Image · Layer Low · Channel RGB
  4. 16-bit: Add · Invert ✓ · Scale 2 · Offset 0  |  8-bit: Subtract · Scale 2 · Offset 128
  5. High → Linear Light ✅ looks identical again
NO SECOND RADIUS Apply Image subtracts Low itself. Only the bit depth must match.
Guided build · then dial it back

Fix each layer

  • Low: big soft Healing Brush (Sample: Current Layer) or low-opacity Mixer Brush · redness, tan line, muddy shadow
  • High: Healing Brush / Clone · Sample: Current Layer · blemishes
  • Group Ctrl/⌘+G · opacity 70–85% · pores at 100%?
  • Save skin-retouched.psd
MANTRA Fix color and texture separately, and neither betrays the edit.

L08

Dodge & Burn Sculpting

Paint with light. Build it in whispers.

Follow the bones and the existing light

The face map

  • Dodge (bring forward): forehead center, cheekbone tops, nose bridge & tip, brow bone
  • Burn (push back): eye sockets, sides of the nose, under the cheekbones, under the jaw
LIGHT FROM THE LEFT? Dodge the left planes more, burn the right more.
Guided build

The 50% gray layer

  1. Layer ▸ New ▸ Layer · Mode Soft Light · tick Fill with Soft-Light-neutral color (50% gray)
  2. Soft round · Hardness 0 · Flow 5–10% · Opacity 100%
  3. Black: burn the recesses · X · white: dodge the highlights
  4. Temporary Black & White layer to check form · then delete it
  5. Lower opacity until it's felt, not seen · save portrait-sculpted.psd
WATCH Gray layer above the L07 group, not inside it.
Lab · then Now You

Sculpt the face

  • Write the light direction and your 3 dodge / 3 burn zones first
  • Many light passes · no streaks, no edges
  • B&W check done · opacity tuned
  • Now You: three moods, or l08-apple-flat.jpg
MANTRA Build light in whispers, and the sculpting stays invisible.

L09

Eyes, Teeth & Hair

Local, masked, restrained. The Module 3 deliverable.

The shape of every finish

Adjust · mask black · paint back

  • Eyes: Curves lift + optional High Pass · iris & whites
  • Teeth: Hue/Sat · Yellows down first, then Master lightness up
  • Hair: empty layer · Clone/Heal · Sample: All Layers
NOT TOOTHPASTE-WHITE Whites faintly gray or pink, teeth faintly warm.
Guided build

Finish the portrait

  1. Curves · invert mask Ctrl/⌘+I · paint iris & whites
  2. Optional: merged copy Ctrl+Alt+Shift+E / ⌘⌥⇧E · High Pass 1–3 px · Overlay/Soft Light · Alt/⌥-click Add Layer Mask · iris only
  3. Hue/Sat on the teeth · feather the gum line
  4. Hair: short strokes along the flow · fill the gap · leave a few strays
SACRED Never paint out the catchlight.
Final review · in pairs

Flip, toggle, deliver

  • View ▸ Flip Horizontal: flips the view only (Flip Canvas flips pixels)
  • Toggle all Module 3 work off and on
  • "A good day, or a retouch?" Critique the edit, not the face
  • Save the finished layered file under a new name
