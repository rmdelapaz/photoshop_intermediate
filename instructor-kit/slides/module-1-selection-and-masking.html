L01

Luminosity Masks

Two exposures, one frame.

Mental model

The image paints the mask

  • A Lights mask is a grayscale copy of the photo's luminance
  • Bright = white = selected · dark = black = protected
  • Perfect edges: as soft as the light itself, no halos
  • Self-targeting: the sky is the bright part
  • Invert Lights → Darks · intersect Lights → brightest band
Channels panel · on the RGB thumbnail

Four modifiers, one habit

Ctrl/⌘-click → load Lights
+ Shift → add
+ Alt/⌥ → subtract
+ Shift + Alt/⌥ → intersect (narrow to extreme tones)
WATCH the RGB channel, not the layer thumbnail in Layers
Guided build · luminosity-working.psd

Rescue the landscape

  1. 16-bit, Save As; read the histogram; Ctrl/⌘-click RGB
  2. Curves layer → pull down → sky back (spill? intersect first)
  3. Reload, invert Ctrl/⌘ShiftI → Curves → lift shadows
  4. 100% along the horizon: no seam, no glow · Save
WHY one S-curve can't push highlights down and shadows up at once
Checklist

Done when…

  • Highlights recovered through a Lights (RGB) mask
  • Shadows lifted through an inverted Darks mask
  • No seam or halo at the horizon at 100%
  • Every edit an adjustment layer with a luminosity mask · 16-bit

L02

Channel Masking & Blend-If

Shop the channels before you paint.

Mental model

Three masks you already have

  • Every RGB image = Red + Green + Blue, three grayscale pictures
  • Find the one with the most subject/background separation
  • Skies are blue → the Blue channel keeps sky bright, branches dark
  • Duplicate → Levels → load → mask
Guided build · channel-working.psd

Extract a tree

  1. Click R, G, B: pick the highest contrast (Blue)
  2. Drag it to New Channel → Image ▸ Adjustments ▸ Levels on the copy
  3. Ctrl/⌘-click the copy → invert → click RGB → add layer mask
  4. Place l02-new-sky.jpg below; check twigs at 100%
WATCH don't over-push: fine twigs go white and vanish

When to use which

Fast and tonal, or editable and spatial

  • Blend-If: instant, non-destructive, tone-global
  • Channel mask: editable, spatial, paint on it after
  • Luminosity mask: tonal bands for adjustments
  • Hard subjects: usually a combination

L03

The Hard Cutout

Every strand survives.

A pipeline, not a tool

Rough in → refine → rescue → decontaminate

  1. Rough in: Select ▸ Subject, the solid mass (ignore wisps)
  2. Refine: Refine Edge Brush on the hairline
  3. Rescue: channel mask, paint white into the layer mask
  4. Decontaminate: the old background's color lets go
RULE don't expect step one to do step three's job
Select and Mask · Ctrl/⌘ + Alt/⌥ + R

Tuned for hair

  • Edge Detection: Smart Radius on, Radius up a few px; try Refine Hair
  • Refine Edge Brush along the hairline, never across solid hair
  • Smooth & Feather low · Shift Edge slightly negative
  • Output: New Layer with Layer Mask · Decontaminate off for now
Guided build · cutout-working.psd

Rescue, then decontaminate

  1. Best hair channel → duplicate → Levels → Ctrl/⌘-click → invert
  2. Click the mask thumbnail; soft, low-opacity white along the hairline
  3. Reopen Select and Mask on that mask → Decontaminate Colors, raise Amount
  4. Output New Layer with Layer Mask → saturated color layer behind
WATCH hide the original, or every cutout looks perfect
