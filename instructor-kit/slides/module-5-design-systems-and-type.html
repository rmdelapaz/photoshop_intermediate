  • Roles on steps; never freehand a size

Styles & OpenType

Decide once, apply everywhere

  • Window ▸ Paragraph Styles and ▸ Character Styles (two panels)
  • A style = font, size, leading, tracking, color, OpenType
  • OpenType buttons along the bottom of the Character panel: ligatures, small caps, oldstyle figures
  • Edit the style once → every instance updates
NEVER Faux Bold / Faux Italic: real weight, or a different face
Columns × baselines

Photoshop has no baseline grid. Build one.

  1. View ▸ Guides ▸ New Guide Layout: columns, gutter, margins
  2. Preferences ▸ Guides, Grid & Slices: Gridline Every = body leading (24 px), Subdivisions 1
  3. Leading = grid increment (or a multiple)
  4. Show grid Ctrl/⌘'; nudge the first baseline onto a line
WATCH Snap To ▸ Grid snaps layer edges, not baselines: check by eye

L14

Smart-Object Templates & Linked Assets

Lesson 5.2 · a container you can refill.

Mental model

The wrapping is the template

  • Warp, filters, styles live on the container
  • Replace Contents swaps the art, keeps the treatment
  • Transform applies to new art: build at the art's exact size
  • Embedded: inside the PSD, independent
  • Linked (Place Linked): one file, many documents
  • Package before handoff
Build a mockup · l14-mockup-poster-wall.jpg

Wrap it, treat it, refill it

  1. Rectangle 1200 × 1800 → Convert to Smart Object
  2. Ctrl/⌘T ▸ Warp to the surface
  3. Multiply shadows + Screen highlights, clipped
  4. Double-click to edit, or Layer ▸ Smart Objects ▸ Replace Contents
TRAP the 1800 × 1200 design comes in wrong: size matters
Linked assets

Change the file, not the documents

  • File ▸ Place Linked logo.png (link badge on the layer)
  • Edit and save the source → every placement refreshes
  • Not updating? Layer ▸ Smart Objects ▸ Update All Modified Content
  • Moved or renamed? Warning → Relink to File

Share, recompose, export

  1. New doc (RGB), Artboards on; add the four sizes
  2. Place Linked logo + key art into each; apply the L13 styles
  3. Recompose: anchor the focal point; stack · center · spread
  4. File ▸ Export ▸ Export As: all artboards, one pass
WATCH safe zones: story top & bottom, banner edges · adjustment layers can't be linked
Prove it

One edit, every size

  • Open the linked logo or key art, change it, save
  • Every artboard updates (else Update All Modified Content)
  • Re-export the whole set
  • What stayed identical? What was recomposed?
