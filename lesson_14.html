Module 5 • Lesson 2🧩 Smart-Object Templates & Linked Assets

A design you can only use once is a craft; a design that updates itself across ten files is a system. Smart Objects and linked assets turn a layout into a reusable template — change the source art once and every deliverable that references it re-renders.

📚 What You'll Learn

By the end of this lesson, you will be able to:

  • Explain what a Smart Object protects and why it is non-destructive
  • Choose between embedded and linked Smart Objects for a job
  • Build a mockup template with a warped Smart-Object placeholder
  • Use Replace Contents and Place Linked to swap art in one move
  • Update one linked file and have every design using it refresh

👤 The Goal: Change Once, Update Everywhere

🧠 Mental Model: A Container You Can Refill

A Smart Object wraps one or more layers in a protective container. Scale it down and back up and it stays sharp; apply a filter and it becomes an editable Smart Filter you can retune later; double-click it and you edit its contents in their own tab, then save and the parent updates. Nothing you do to the container destroys what is inside.

The container also has a superpower: Replace Contents. Any transforms, warps, filters, and layer styles you applied to the container stay put while the artwork inside is swapped. That is what makes templates possible — the wrapping is the template, the contents are the variable.

🔗 Embedded vs Linked

An embedded Smart Object stores its contents inside the PSD — portable, self-contained, but each copy is independent. A linked Smart Object (File ▸ Place Linked) points at an external file on disk; many documents can link the same file, and editing that one file updates them all on open. Embedded is best for one-off protection; linked is the backbone of a multi-file system.

⚠️ Linked files can go missing

Move or rename a linked file and Photoshop loses it (the layer shows a warning). Keep linked assets in a project folder you don't reshuffle, and Package the project before sending it on. The power of links comes with the discipline of not moving them.

🖼️ Building a Mockup Placeholder

A mockup (art on a mug, a billboard, a phone screen) is just a Smart Object placeholder shaped to the surface. Build it once: put a plain rectangle Smart Object where the art goes, warp it to the surface's perspective, then add the surface's shadow and highlight above it on Multiply/Screen layers. Forever after, Replace Contents drops any new art straight onto that surface, lit and warped.

✅ Effects on the container, not the art

Apply the warp, shadows, and blend modes to the placeholder Smart Object and the layers around it — never bake them into the art itself. Then the art stays a clean, swappable rectangle and the treatment is permanent. That separation is the entire trick of a good mockup.

🛠️ Guided Build: A Reusable Template

Grab a photo of a surface you want to brand — a mug, a poster on a wall, a laptop lid.

Step 1: Place the placeholder · 8 min

  1. Make a rectangle roughly the size of the art area. Right-click ▸ Convert to Smart Object.
  2. Free Transform ▸ Warp (or Perspective Warp) to conform it to the surface's shape and angle.

Step 2: Light it into the scene · 10 min

  1. Above the placeholder, add a layer set to Multiply and paint the surface's existing shadows/creases back over the art.
  2. Add a Screen layer for highlights/reflections. Clip both to the placeholder so they only affect the art area.

Step 3: Swap in real art · 8 min

  1. Double-click the placeholder (opens its own tab), paste or place your design, save, close. It flows onto the surface, warped and lit.
  2. Prefer Place Linked for the art if several mockups should share it — then one edit updates them all.

Step 4: Prove reuse · 6 min

  1. Replace Contents with a different design. The perspective, shadows, and highlights hold automatically.
  2. Save this file as your reusable mockup template. 🏆

✅ Project Completion Checklist

  • ☐ Placeholder is a Smart Object, warped to the surface
  • ☐ Shadows (Multiply) + highlights (Screen) on the container, clipped
  • ☐ Art swaps via Replace Contents / double-click edit
  • ☐ Shared art uses Place Linked where appropriate
  • ☐ Saved as a reusable template; Package if handing off

🧗 Now You: Solo Variation

🌟 Your challenge

  1. Build a three-surface mockup (front, side, angled) and drop one design across all three at once via a shared linked file.
  2. Make a "brand sheet" PSD whose logo is a linked SO; then change the logo file and watch every placement update on reopen.
  3. Turn a filter you use often into a Smart Filter on a Smart Object and retune it a week later without redoing the layer.

Going further: nest Smart Objects — a placeholder inside a placeholder — so a whole sub-design (with its own type system from 5.1) becomes one swappable unit.

🍳 Recipe Card: Smart-Object Template

Wrap it, treat it, refill it

  1. Rectangle → Convert to Smart Object placeholder
  2. Warp to the surface; add Multiply shadows + Screen highlights (clipped)
  3. Double-click to edit contents, or Replace Contents to swap
  4. Place Linked for art shared across files
  5. Package the project before handoff so links survive

Mantra: put the treatment on the container and the artwork stays free to change.

Why .psb for linked files, not .psd?

Either works; large-format or high-bit files may exceed the 2GB PSD limit, and PSB (large document format) handles them. For most brand assets a PSD or even a PNG/SVG linked file is fine.

Do Smart Objects make my file huge?

Embedded ones add the contents' full weight to the PSD. Linked ones keep the data external, so the working file stays lighter. That is another reason linked assets scale better across a big project.
